Language INtegrated Queries (LINQ)¶

Seni oleme andmetega töötanud käsitsi — käinud massiive ja loendeid läbi tsüklitega, võtnud elemente indeksite järgi ja teinud võrdlusi. LINQ pakub palju lühemat ja loetavamat viisi andmete filtreerimiseks, sorteerimiseks ja töötlemiseks.

Mis on LINQ?¶

LINQ on C# keele osa, mis võimaldab küsida andmeid massiividelt ja loenditelt sarnaselt andmebaasi päringuga. Selle asemel, et kirjutada pikk for-tsükkel koos if-lausetega, kirjutame ühe rea, mis ütleb arvutile täpselt, mida me tahame.

Lühidalt: LINQ asendab tüütud tsüklid kompaktsete päringutega.

Esimene näide — ilma LINQ ja sellega¶

Vaata, kuidas sama ülesannet lahendatakse kahel viisil.

Ilma LINQ¶

int[] numbrid = { 5, 12, 3, 19, 7, 21, 8 };

// Soovime ainult paarisarve
List<int> paarisarvud = new List<int>();
for (int i = 0; i < numbrid.Length; i++)
{
    if (numbrid[i] % 2 == 0)
    {
        paarisarvud.Add(numbrid[i]);
    }
}

foreach (int nr in paarisarvud)
{
    Console.WriteLine(nr);
}

LINQ-ga¶

using System.Linq;

int[] numbrid = { 5, 12, 3, 19, 7, 21, 8 };

var paarisarvud = numbrid.Where(n => n % 2 == 0);

foreach (int nr in paarisarvud)
{
    Console.WriteLine(nr);
}

Mõlemad programmid annavad sama tulemuse: 12, 8. Teine variant on lühem ja selgem.

Lisatud using System.Linq

LINQ kasutamiseks peame lisama programmi ülaossa rea using System.Linq;. Ilma selleta C# LINQ meetodeid ei tunne.

Peamised LINQ meetodid¶

.Where() — filtreerimine¶

.Where() võtab kogu ja jätab alles ainult need elemendid, mis vastavad tingimusele.

using System.Linq;

string[] linnad = { "Tallinn", "Tartu", "Pärnu", "Narva", "Kuressaare" };

// Ainult linnad, mis algavad T-ga
var tLinnad = linnad.Where(l => l.StartsWith("T"));

foreach (string linn in tLinnad)
{
    Console.WriteLine(linn); // Tallinn, Tartu
}

using System.Linq;

int[] hinded = { 5, 3, 4, 5, 2, 5, 4 };

// Ainult viied
var viied = hinded.Where(h => h == 5);

Console.WriteLine("Viite hindeid on: " + viied.Count()); // 3

.Select() — väärtuste muutmine¶

.Select() võtab iga elemendi ja muudab selle mingil viisil.

using System.Linq;

int[] numbrid = { 1, 2, 3, 4, 5 };

// Korruta iga number kolmega
var korrutised = numbrid.Select(n => n * 3);

foreach (int nr in korrutised)
{
    Console.WriteLine(nr); // 3, 6, 9, 12, 15
}

using System.Linq;

string[] nimed = { "Mari", "Jaan", "Kati" };

// Muuda kõik nimed suurtähtedeks
var suuredNimed = nimed.Select(n => n.ToUpper());

foreach (string nimi in suuredNimed)
{
    Console.WriteLine(nimi); // MARI, JAAN, KATI
}

.OrderBy() ja .OrderByDescending() — sorteerimine¶

using System.Linq;

int[] hinded = { 4, 2, 5, 1, 3 };

// Kasvavalt
var kasvavalt = hinded.OrderBy(h => h);
Console.WriteLine("Kasvavalt: " + string.Join(", ", kasvavalt)); // 1, 2, 3, 4, 5

// Kahanevalt
var kahanevalt = hinded.OrderByDescending(h => h);
Console.WriteLine("Kahanevalt: " + string.Join(", ", kahanevalt)); // 5, 4, 3, 2, 1

using System.Linq;

string[] toidud = { "Supp", "Pizza", "Salat", "Apel" };

// Tähestiku järjekorras
var sorteeritud = toidud.OrderBy(t => t);

foreach (string toit in sorteeritud)
{
    Console.WriteLine(toit); // Apel, Pizza, Salat, Supp
}

.First() ja .Last() — esimene ja viimane element¶

using System.Linq;

int[] numbrid = { 10, 20, 30, 40, 50 };

int esimene = numbrid.First();      // 10
int viimane = numbrid.Last();       // 50

Console.WriteLine("Esimene: " + esimene);
Console.WriteLine("Viimane: " + viimane);

.Count() — elementide arv¶

using System.Linq;

int[] numbrid = { 5, 12, 3, 19, 7, 21, 8 };

int koguarv = numbrid.Count();                    // 7
int paarisarve = numbrid.Count(n => n % 2 == 0);  // 2

Console.WriteLine("Kokku: " + koguarv);
Console.WriteLine("Paarisarve: " + paarisarve);

.Sum() ja .Average() — summa ja keskmine¶

using System.Linq;

int[] hinded = { 5, 4, 3, 5, 4, 5, 4 };

int summa = hinded.Sum();
double keskmine = hinded.Average();

Console.WriteLine("Summa: " + summa);        // 30
Console.WriteLine("Keskmine: " + keskmine);  // 4.28...

.Min() ja .Max() — väikseim ja suurim¶

using System.Linq;

int[] hinded = { 5, 4, 3, 5, 4, 5, 4 };

int min = hinded.Min();  // 3
int max = hinded.Max();  // 5

Console.WriteLine("Väikseim: " + min);
Console.WriteLine("Suurim: " + max);

Meetodite aheldamine¶

Tõeline jõud tuleneb sellest, et meetodeid saab aheldada — panna üksteise järele. Iga meetod annab tulemise järgmisele meetodile.

using System.Linq;

int[] hinded = { 5, 3, 4, 5, 2, 5, 4, 1, 3 };

// Sorteeri kasvavalt, võta ainult unikaalsed, võta esimesed 3
var result = hinded
    .OrderBy(h => h)
    .Distinct()
    .Take(3);

foreach (int h in result)
{
    Console.WriteLine(h); // 1, 2, 3
}

using System.Linq;

string[] nimed = { "Mari", "Jaan", "Kati", "Andres", "Maris" };

// Filtreeri nimed, mis algavad M-ga, muuda suurtähtedeks, sorteeri
var result = nimed
    .Where(n => n.StartsWith("M"))
    .Select(n => n.ToUpper())
    .OrderBy(n => n);

foreach (string nimi in result)
{
    Console.WriteLine(nimi); // MARIS, MARI
}

Igapäevaelu näited¶

Koolihinnete analüüs¶

using System.Linq;

int[] hinded = { 5, 4, 3, 5, 4, 5, 4, 2, 5, 3 };

int parim = hinded.Max();
int halvim = hinded.Min();
double keskmine = hinded.Average();
int miinimumHinded = hinded.Count(h => h >= 3);

Console.WriteLine("Parim hinne: " + parim);
Console.WriteLine("Halvim hinne: " + halvim);
Console.WriteLine("Keskmine: " + keskmine.ToString("F1"));
Console.WriteLine("Miinimumi täitnud (≥3): " + miinimumHinded + "/" + hinded.Length);

Tootenimekiri¶

using System.Linq;

List<string> tooted = new List<string> { "Piim", "Leib", "Munad", "Juust", "Õun", "Banaan" };

// Tooted tähestiku järjekorras
var sorteeritud = tooted.OrderBy(t => t);
Console.WriteLine("Tooted A-Z:");
foreach (string toode in sorteeritud)
{
    Console.WriteLine("  " + toode);
}

// Kõik tooted suurtähtedeks
var suured = tooted.Select(t => t.ToUpper());
Console.WriteLine("\nKõik suurtähtedega:");
Console.WriteLine(string.Join(", ", suured));

Bussiliinide võrdlus¶

using System.Linq;

int[] bussideMinutid = { 5, 12, 8, 20, 3, 15, 7 };

int kiireim = bussideMinutid.Min();
int aeglasem = bussideMinutid.Max();
double ooteaeg = bussideMinutid.Average();

Console.WriteLine("Kiireim buss: " + kiireim + " min");
Console.WriteLine("Aeglasem buss: " + aeglasem + " min");
Console.WriteLine("Keskmine ooteaeg: " + ooteaeg.ToString("F1") + " min");

// Bussid, mis tulevad alla 10 minuti
var kiired = bussideMinutid.Where(m => m < 10);
Console.WriteLine("Kiired bussid (<10 min): " + string.Join(", ", kiired));

Sageli tekkinud vead¶

using System.Linq unustamine¶

// VIGA — LINQ meetodid ei tööta
int[] numbrid = { 1, 2, 3 };
var result = numbrid.Where(n => n > 1); // Viga!

// ÕIGE
using System.Linq;
var result2 = numbrid.Where(n => n > 1); // töötab

Lambdalekspressi süntaks¶

// Õige — lambdalekspress
var result = numbrid.Where(n => n > 1);

// VIGA — sulud ja return on liigsed
// var result = numbrid.Where((n) => { return n > 1; });
// See töötab küll, aga on tarbetult pikk

Tulemuse kasutamine¶

using System.Linq;

int[] numbrid = { 1, 2, 3, 4, 5 };

// LINQ on laisk — ta ei tee midagi enne, kui tulemust kasutatakse
var filtered = numbrid.Where(n => n > 3);
// Siin ei ole veel midagi juhtunud!

// Tulemus tekib alles siin
foreach (var nr in filtered)
{
    Console.WriteLine(nr); // alles nüüd käib filtreerimine läbi
}

Kõik meetodid kokkuvõttes¶

Meetod Tähendus Näide
.Where() Filtreeri elemendid .Where(n => n > 5)
.Select() Muuda iga element .Select(n => n * 2)
.OrderBy() Sorteeri kasvavalt .OrderBy(n => n)
.OrderByDescending() Sorteeri kahanevalt .OrderByDescending(n => n)
.First() Esimene element .First()
.Last() Viimane element .Last()
.Count() Elementide arv .Count()
.Count(tingimus) Tingimusele vastavate arv .Count(n => n > 5)
.Sum() Kõikide summa .Sum()
.Average() Keskmine .Average()
.Min() Väikseim .Min()
.Max() Suurim .Max()
.Distinct() Eemalda kordused .Distinct()
.Take(n) Esimesed n elementi .Take(3)
.ToList() Teisenda loendiks .ToList()

Harjutused¶

  1. Loo massiiv 10 juhuslikust numbrit (1–50). Kasuta LINQ-d, et leia summa, keskmine, suurim ja väikseim number.
  2. Loo loend 7 lemmikfilmiga. Filtreeri välja ainult filmid, mille nimi on pikem kui 6 tähemärki. Sorteeri tulemus tähestiku järjekorras.
  3. Loo massiiv 10 õpilase hinnetega. Arvuta välja mitu õpilast on saanud vähemalt 4. Kasuta .Count() tingimusega.
  4. Loo loend 5 linnaga. Muuda iga linna nimi suurtähtedeks ja prindi tulemus välja ühel real, komadega eraldatuna (string.Join).
