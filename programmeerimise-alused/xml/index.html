Töötamine XML-formaadis andmetega¶

Failide peatükis salvestasime andmeid lihtsatesse tekstifailidesse ja streamide peatükis õppisime suuri faile tükikaupa töötlema. Aga tekstifailil on üks suur puudus: arvuti jaoks on see lihtsalt ridade jada, millel puudub igasugune struktuur. Kui tahame salvestada keerukamat infot — näiteks nimekirja õpilastest koos nende nimede, vanuste ja hinnetega —, siis tuleb faili struktuuri ise kokku leppida.

XML (eXtensible Markup Language) on tekstipõhine vorming, mis annab andmetele struktuuri. XML-i abil saame andmeid kirjeldada nii, et nii inimene kui ka programm mõistavad, mis on mis. XML-i kasutavad paljud programmid andmete vahetamiseks ja hoidmiseks — näiteks seadete failid, veebiteenused ja dokumendivormingud.

XML vs tekstifail

Tekstifailis on lihtsalt read nagu Mari,16. XML-is on sama info kirjeldatud siltidega, mis ütlevad, mida iga väärtus tähendab. Nii ei sõltu programm enam sellest, mitmendal kohal andmed asuvad.

Mis on XML?¶

XML-fail koosneb elementidest. Iga element algab avava sildiga nagu <nimi> ja lõpeb sulgeva sildiga nagu </nimi>. Nende vahel on elemendi sisu.

<?xml version="1.0" encoding="utf-8"?>
<opilased>
    <opilane>
        <nimi>Mari</nimi>
        <vanus>16</vanus>
        <hinne>4</hinne>
    </opilane>
    <opilane>
        <nimi>Jaan</nimi>
        <vanus>17</vanus>
        <hinne>5</hinne>
    </opilane>
</opilased>

Selles näites:

  • <?xml ... ?> on deklaratsioon, mis ütleb, et tegemist on XML-failiga ja millist kodeeringut kasutatakse.
  • <opilased> on juurelement (root). XML-failil saab olla täpselt üks juurelement, mille sees on kõik ülejäänu.
  • <opilane> on iga õpilase kirje, mille sees on omakorda <nimi>, <vanus> ja <hinne>.
  • Sildid on pesastatud (nested) — sarnaselt loogikaga, kuidas plokid on üksteise sees.

Elementidel võivad olla ka atribuudid — lisanväärtused avava sildi sees:

<opilane id="1" klass="A">
    <nimi>Mari</nimi>
</opilane>

Siin on id ja klass atribuudid. Atribuut sobib hästi lühikese, elemendi juurde kuuluva lisainfo jaoks.

Sildid peavad olema paaris

Iga avav silt peab olema korrektselt suletud. <nimi>Mari</nimi> on korrektne, <nimi>Mari on viga. Erinevalt HTML-ist, kus mõned sildid võivad olla sulgemata, on XML palju rangem.

XML nimeruumid¶

XML-iga töötamiseks on .NET-is mitu klassi, mis asuvad erinevates nimeruumides:

Nimeruum Milleks
System.Xml Klassikaline XmlDocument ja XmlNode
System.Xml.Linq Kaasaegne LINQ-to-XML: XDocument ja XElement
System.Xml.Serialization Objektide serialiseerimine ja deserialiseerimine

Lisame need sõltuvalt vajadusest programmi ülaossa:

using System.Xml;
using System.Xml.Linq;
using System.Xml.Serialization;

Lugemine XmlDocument-iga¶

Klassikaline viis XML-i lugemiseks on XmlDocument. Fail laetakse mällu meetodiga Load() ja seejärel saab elemente otsida XPath-päringute abil.

using System.Xml;

XmlDocument doc = new XmlDocument();
doc.Load(@"C:\temp\opilased.xml");

XmlNodeList opilased = doc.SelectNodes("/opilased/opilane");

foreach (XmlNode opilane in opilased)
{
    string nimi = opilane.SelectSingleNode("nimi").InnerText;
    string vanus = opilane.SelectSingleNode("vanus").InnerText;
    Console.WriteLine(nimi + " (" + vanus + ")");
}

using System;
using System.Xml;

namespace XmlApp
{
    class Program
    {
        static void Main(string[] args)
        {
            XmlDocument doc = new XmlDocument();
            doc.Load(@"C:\temp\opilased.xml");

            XmlNodeList opilased = doc.SelectNodes("/opilased/opilane");

            foreach (XmlNode opilane in opilased)
            {
                string nimi = opilane.SelectSingleNode("nimi").InnerText;
                string vanus = opilane.SelectSingleNode("vanus").InnerText;
                Console.WriteLine(nimi + " (" + vanus + ")");
            }
        }
    }
}

Mõned olulised asjad selles näites:

  • SelectNodes("/opilased/opilane") otsib kõik opilane elemendid, mis asuvad opilased elemendi sees. Sellist teed nimetatakse XPath-iks.
  • SelectSingleNode("nimi") leiab elemendi sees esimese nimi elemendi.
  • InnerText annab elemendi tekstilise sisu.

XPath

XPath on tee kirjeldamise keel XML-i puus. Kaldkriips / tähendab liikumist juurest allapoole, nagu C:\temp\fail.txt failisüsteemis. XPath oskab palju enamat (näiteks //nimi otsib kõiki nimi elemente ükskõik kui sügavalt), aga alustuseks piisab lihtsast teest.

Atribuutide lugemine¶

Atribuudile pääseb ligi Attributes kogumiku ja GetAttribute() meetodi kaudu:

using System.Xml;

XmlDocument doc = new XmlDocument();
doc.Load(@"C:\temp\opilased.xml");

foreach (XmlNode opilane in doc.SelectNodes("/opilased/opilane"))
{
    string id = opilane.Attributes["id"].Value;
    string nimi = opilane.SelectSingleNode("nimi").InnerText;
    Console.WriteLine("#" + id + " " + nimi);
}

Lugemine XDocument-iga (LINQ to XML)¶

Kaasaegsem ja lühem viis on XDocument nimeruumist System.Xml.Linq. See lubab XML-i peal kasutada LINQ-päringuid, mida LINQ peatükist juba tunneme.

using System.Xml.Linq;

XDocument doc = XDocument.Load(@"C:\temp\opilased.xml");

foreach (XElement opilane in doc.Root.Elements("opilane"))
{
    string nimi = opilane.Element("nimi").Value;
    string vanus = opilane.Element("vanus").Value;
    Console.WriteLine(nimi + " (" + vanus + ")");
}

using System;
using System.Xml.Linq;

namespace XmlApp
{
    class Program
    {
        static void Main(string[] args)
        {
            XDocument doc = XDocument.Load(@"C:\temp\opilased.xml");

            foreach (XElement opilane in doc.Root.Elements("opilane"))
            {
                string nimi = opilane.Element("nimi").Value;
                string vanus = opilane.Element("vanus").Value;
                Console.WriteLine(nimi + " (" + vanus + ")");
            }
        }
    }
}

XDocument-i puhul:

  • doc.Root on juurelement.
  • Elements("opilane") annab kõik opilane lapsed.
  • Element("nimi") annab ühe lapse nime järgi.
  • Value annab elemendi tekstilise sisu.

Filtreerimine LINQ-iga¶

Kuna XDocument annab tavalise loendi, saame kohe peale panna LINQ-meetodid. Loeme näiteks ainult need õpilased, kelle hinne on vähemalt 5:

using System.Xml.Linq;

XDocument doc = XDocument.Load(@"C:\temp\opilased.xml");

var parimad = doc.Root.Elements("opilane")
    .Where(o => int.Parse(o.Element("hinne").Value) >= 5)
    .Select(o => o.Element("nimi").Value);

foreach (string nimi in parimad)
{
    Console.WriteLine(nimi);
}

XML-i kirjutamine¶

Kirjutamine XmlDocument-iga¶

Uue XML-i ehitamine XmlDocument-iga on sõnaline: iga element tuleb eraldi luua ja üles ehitada.

using System.Xml;

XmlDocument doc = new XmlDocument();

XmlElement root = doc.CreateElement("opilased");
doc.AppendChild(root);

XmlElement opilane = doc.CreateElement("opilane");
root.AppendChild(opilane);

XmlElement nimi = doc.CreateElement("nimi");
nimi.InnerText = "Mari";
opilane.AppendChild(nimi);

XmlElement vanus = doc.CreateElement("vanus");
vanus.InnerText = "16";
opilane.AppendChild(vanus);

doc.Save(@"C:\temp\opilased.xml");

using System.Xml;

namespace XmlApp
{
    class Program
    {
        static void Main(string[] args)
        {
            XmlDocument doc = new XmlDocument();

            XmlElement root = doc.CreateElement("opilased");
            doc.AppendChild(root);

            XmlElement opilane = doc.CreateElement("opilane");
            root.AppendChild(opilane);

            XmlElement nimi = doc.CreateElement("nimi");
            nimi.InnerText = "Mari";
            opilane.AppendChild(nimi);

            XmlElement vanus = doc.CreateElement("vanus");
            vanus.InnerText = "16";
            opilane.AppendChild(vanus);

            doc.Save(@"C:\temp\opilased.xml");
        }
    }
}

Save() kirjutab valminud dokumendi faili. Tulemuseks on korrektselt vormindatud XML.

Kirjutamine XDocument-iga¶

XDocument teeb sama asja palju lühemalt, sest elemendid saab luua ühe avaldise sees pesastatult.

using System.Xml.Linq;

XDocument doc = new XDocument(
    new XElement("opilased",
        new XElement("opilane",
            new XElement("nimi", "Mari"),
            new XElement("vanus", 16),
            new XElement("hinne", 4)
        )
    )
);

doc.Save(@"C:\temp\opilased.xml");

using System;
using System.Xml.Linq;

namespace XmlApp
{
    class Program
    {
        static void Main(string[] args)
        {
            XDocument doc = new XDocument(
                new XElement("opilased",
                    new XElement("opilane",
                        new XElement("nimi", "Mari"),
                        new XElement("vanus", 16),
                        new XElement("hinne", 4)
                    )
                )
            );

            doc.Save(@"C:\temp\opilased.xml");
        }
    }
}

Pööra tähelepanu, et new XElement("vanus", 16) võtab teiseks argumendiks juba arvu — XDocument teisendab selle ise tekstiks. Avatud dokumendi saab konsoolile trükkida meetodiga doc.ToString().

Mitme elemendi lisamine loendist¶

Kuna XElement võtab vastu mistahes arvu elemente, saab loendist mugavalt mitu kirjet korraga teha:

using System.Xml.Linq;

string[] nimed = { "Mari", "Jaan", "Kati" };

XDocument doc = new XDocument(
    new XElement("nimed",
        nimed.Select(n => new XElement("nimi", n))
    )
);

doc.Save(@"C:\temp\nimed.xml");

Tulemus:

<?xml version="1.0" encoding="utf-8"?>
<nimed>
  <nimi>Mari</nimi>
  <nimi>Jaan</nimi>
  <nimi>Kati</nimi>
</nimed>

Serialiseerimine¶

Senimaani pidime iga XML-elemendi ise kokku panema. Kui aga andmed on juba C#-klassi kujul, on olemas mugavam viis: serialiseerimine ehk objekti muutmine XML-iks.

Klass XmlSerializer (nimeruumist System.Xml.Serialization) teeb töö meie eest ära. Ta vaatab klassi omadusi (properties) ja kirjutab need XML-i.

Alustame lihtsa klassiga:

public class Opilane
{
    public string Nimi { get; set; }
    public int Vanus { get; set; }
    public int Hinne { get; set; }
}

Serialiseerimine ehk objekti kirjutamine XML-faili:

using System.IO;
using System.Xml.Serialization;

Opilane opilane = new Opilane
{
    Nimi = "Mari",
    Vanus = 16,
    Hinne = 4
};

XmlSerializer serializer = new XmlSerializer(typeof(Opilane));

using (StreamWriter writer = new StreamWriter(@"C:\temp\opilane.xml"))
{
    serializer.Serialize(writer, opilane);
}

using System.IO;
using System.Xml.Serialization;

namespace XmlApp
{
    public class Opilane
    {
        public string Nimi { get; set; }
        public int Vanus { get; set; }
        public int Hinne { get; set; }
    }

    class Program
    {
        static void Main(string[] args)
        {
            Opilane opilane = new Opilane
            {
                Nimi = "Mari",
                Vanus = 16,
                Hinne = 4
            };

            XmlSerializer serializer = new XmlSerializer(typeof(Opilane));

            using (StreamWriter writer = new StreamWriter(@"C:\temp\opilane.xml"))
            {
                serializer.Serialize(writer, opilane);
            }
        }
    }
}

Tulemuseks on fail:

<?xml version="1.0" encoding="utf-8"?>
<Opilane xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xmlns:xsd="http://www.w3.org/2001/XMLSchema">
  <Nimi>Mari</Nimi>
  <Vanus>16</Vanus>
  <Hinne>4</Hinne>
</Opilane>

XmlSerializer kasutab juurelemendi nimeks klassi nime (Opilane) ja iga omaduse jaoks loob samanimelise elemendi.

Streamidega koostöö

Serialiseerija ei kirjuta otse faili, vaid suvalisse voogu. StreamWriter avab faili, Serialize() kirjutab sinna objekti. Sama toimub ka streamide peatükist tuntud loogika järgi. Serialiseerida saab ka otse File.Create() abil loodud voogu.

Klassi- ja elemendinimede muutmine¶

Atribuutide abil saab XML-i nimesid ümber nimetada, kui need erinevad klassi omaduste nimedest. Näiteks kui tahame juurelemendiks opilane (väikese tähega) ja inglisekeelseid elemendinimesid:

using System.Xml.Serialization;

[XmlRoot("opilane")]
public class Opilane
{
    [XmlElement("name")]
    public string Nimi { get; set; }

    [XmlElement("age")]
    public int Vanus { get; set; }
}

Nüüd tekib XML kujul:

<?xml version="1.0" encoding="utf-8"?>
<opilane>
  <name>Mari</name>
  <age>16</age>
</opilane>

Loendi serialiseerimine¶

Ka loendi saab korraga serialiseerida. XmlSerializer loob sel juhul juurelemendi nimega ArrayOfOpilane:

using System.Collections.Generic;
using System.IO;
using System.Xml.Serialization;

List<Opilane> opilased = new List<Opilane>
{
    new Opilane { Nimi = "Mari", Vanus = 16, Hinne = 4 },
    new Opilane { Nimi = "Jaan", Vanus = 17, Hinne = 5 }
};

XmlSerializer serializer = new XmlSerializer(typeof(List<Opilane>));

using (StreamWriter writer = new StreamWriter(@"C:\temp\opilased.xml"))
{
    serializer.Serialize(writer, opilased);
}

Tulemus:

<?xml version="1.0" encoding="utf-8"?>
<ArrayOfOpilane>
  <Opilane>
    <Nimi>Mari</Nimi>
    <Vanus>16</Vanus>
    <Hinne>4</Hinne>
  </Opilane>
  <Opilane>
    <Nimi>Jaan</Nimi>
    <Vanus>17</Vanus>
    <Hinne>5</Hinne>
  </Opilane>
</ArrayOfOpilane>

Deserialiseerimine¶

Deserialiseerimine on vastupidine tegevus: XML-ist saab jälle C#-objekt. Kasutame sama XmlSerializer-it, aga seekord lugemiseks.

Oluline on, et XML-i struktuur vastaks täpselt klassile, milleks me seda teisendame.

using System.IO;
using System.Xml.Serialization;

XmlSerializer serializer = new XmlSerializer(typeof(Opilane));

Opilane opilane;

using (StreamReader reader = new StreamReader(@"C:\temp\opilane.xml"))
{
    opilane = (Opilane)serializer.Deserialize(reader);
}

Console.WriteLine(opilane.Nimi);
Console.WriteLine(opilane.Vanus);
Console.WriteLine(opilane.Hinne);

using System;
using System.IO;
using System.Xml.Serialization;

namespace XmlApp
{
    public class Opilane
    {
        public string Nimi { get; set; }
        public int Vanus { get; set; }
        public int Hinne { get; set; }
    }

    class Program
    {
        static void Main(string[] args)
        {
            XmlSerializer serializer = new XmlSerializer(typeof(Opilane));

            Opilane opilane;

            using (StreamReader reader = new StreamReader(@"C:\temp\opilane.xml"))
            {
                opilane = (Opilane)serializer.Deserialize(reader);
            }

            Console.WriteLine(opilane.Nimi);
            Console.WriteLine(opilane.Vanus);
            Console.WriteLine(opilane.Hinne);
        }
    }
}

Deserialize() tagastab alati tüübi object, seetõttu tuleb tulemus klassi nime ette kirjutades konverteerida: (Opilane)serializer.Deserialize(reader).

Loendi deserialiseerimine¶

Loendi lugemisel kasutame sama tüüpi, millega serialiseerisime — List<Opilane>:

using System.Collections.Generic;
using System.IO;
using System.Xml.Serialization;

XmlSerializer serializer = new XmlSerializer(typeof(List<Opilane>));

List<Opilane> opilased;

using (StreamReader reader = new StreamReader(@"C:\temp\opilased.xml"))
{
    opilased = (List<Opilane>)serializer.Deserialize(reader);
}

foreach (Opilane opilane in opilased)
{
    Console.WriteLine(opilane.Nimi + " — hinne " + opilane.Hinne);
}

Näide: õpilaste nimekiri XML-is¶

Paneme seni õpitu kokku. Programmis on klass Opilane, loome mitu õpilast, salvestame need XML-i ja loeme seejärel tagasi.

using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Xml.Serialization;

public class Opilane
{
    public string Nimi { get; set; }
    public int Vanus { get; set; }
    public int Hinne { get; set; }
}

string tee = @"C:\temp\opilased.xml";

List<Opilane> opilased = new List<Opilane>
{
    new Opilane { Nimi = "Mari", Vanus = 16, Hinne = 4 },
    new Opilane { Nimi = "Jaan", Vanus = 17, Hinne = 5 },
    new Opilane { Nimi = "Kati", Vanus = 16, Hinne = 3 }
};

XmlSerializer serializer = new XmlSerializer(typeof(List<Opilane>));

using (StreamWriter writer = new StreamWriter(tee))
{
    serializer.Serialize(writer, opilased);
}

Console.WriteLine("Opilased salvestatud.");

List<Opilane> loetud;

using (StreamReader reader = new StreamReader(tee))
{
    loetud = (List<Opilane>)serializer.Deserialize(reader);
}

Console.WriteLine("Parim keskmine hinne: " + loetud.Average(o => o.Hinne).ToString("F1"));

using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Xml.Serialization;

namespace XmlApp
{
    public class Opilane
    {
        public string Nimi { get; set; }
        public int Vanus { get; set; }
        public int Hinne { get; set; }
    }

    class Program
    {
        static void Main(string[] args)
        {
            string tee = @"C:\temp\opilased.xml";

            List<Opilane> opilased = new List<Opilane>
            {
                new Opilane { Nimi = "Mari", Vanus = 16, Hinne = 4 },
                new Opilane { Nimi = "Jaan", Vanus = 17, Hinne = 5 },
                new Opilane { Nimi = "Kati", Vanus = 16, Hinne = 3 }
            };

            XmlSerializer serializer = new XmlSerializer(typeof(List<Opilane>));

            using (StreamWriter writer = new StreamWriter(tee))
            {
                serializer.Serialize(writer, opilased);
            }

            Console.WriteLine("Opilased salvestatud.");

            List<Opilane> loetud;

            using (StreamReader reader = new StreamReader(tee))
            {
                loetud = (List<Opilane>)serializer.Deserialize(reader);
            }

            Console.WriteLine("Keskmine hinne: " + loetud.Average(o => o.Hinne).ToString("F1"));
        }
    }
}

Ehitada XML-i nullist käsitsi XDocument

Sageli tekkinud vead¶

Nimeruumi puudumine¶

// VIGA — XDocument klass puudub
XDocument doc = XDocument.Load(tee); // Viga!

// ÕIGE
using System.Xml.Linq;
XDocument doc = XDocument.Load(tee);

Deserialiseerimisel vale tüüp¶

using System.Xml.Serialization;

// VIGA — XML-i juur on <ArrayOfOpilane>, aga ootame üksikut Opilane objekti
XmlSerializer serializer = new XmlSerializer(typeof(Opilane));
object tulemus = serializer.Deserialize(reader); // Viga!

// ÕIGE — tüüp peab vastama XML-i struktuurile
XmlSerializer serializer2 = new XmlSerializer(typeof(List<Opilane>));
List<Opilane> opilased = (List<Opilane>)serializer2.Deserialize(reader);

Deserialiseerimine ilma konverteerimiseta¶

using System.Xml.Serialization;

// VIGA — Deserialize() tagastab object-tüübi, millel pole Nimi omadust
var opilane = serializer.Deserialize(reader);
Console.WriteLine(opilane.Nimi); // Viga!

// ÕIGE — konverteerime tagasi Opilane tüübiks
Opilane opilane2 = (Opilane)serializer.Deserialize(reader);
Console.WriteLine(opilane2.Nimi);

Harjutused¶

  1. Loo käsitsi (XDocument-iga) XML-fail raamatud.xml, mis sisaldab vähemalt kahte raamatut. Igal raamatul olgu pealkiri, autor ja aasta element.
  2. Kirjuta programm, mis loeb raamatud.xml failist XDocument.Load() abil kõik raamatud ja trükib need konsoolile kujul Autor — Pealkiri (aasta).
  3. Loo klass Raamat omadustega Pealkiri, Autor ja Aasta. Serialiseeri List<Raamat> faili raamatud.xml ja seejärel deserialiseeri see kohe tagasi ning trüki tulemus konsoolile. Kontrolli, et failis olev XML näeb välja loetav.
  4. Loe raamatud.xml failist andmed XDocument-iga ja kasuta LINQ-it, et leida kõik raamatud, mis on ilmunud pärast 2010. aastat. Trüki tulemus.
  5. Loo programm, mis küsib kasutajalt kordamööda raamatu pealkirja, autori ja aasta, lisab need loendisse ning serialiseerib lõpuks kogu nimekirja XML-faili. Küsimine lõpeb, kui kasutaja jätab pealkirja tühjaks.
