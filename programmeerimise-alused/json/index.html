Töötamine JSON-formaadis andmetega¶

XML peatükis õppisime andmeid struktuurselt tekstifaili salvestama. XML on võimas ja paindlik, aga mõnikord liiga sõnaline — iga väärtuse jaoks tuleb kirjutada avav ja sulgev silt. Seal, kus on vaja lihtsat ja kompaktset andmevormingut, kasutatakse tihti hoopis JSON-it.

JSON (JavaScript Object Notation) on kerge tekstipõhine andmevorming. See on kiiresti loetav nii inimesele kui ka programmile ning seda kasutavad peaaegu kõik tänapäeva veebiteenused andmete vahetamiseks. Kui suheldakse näiteks ilmateenistuse või mõne muu API-ga, tulevad andmed väga sageli just JSON-kujul.

XML vs JSON

XML kasutab silte <nimi>Mari</nimi>, JSON aga võti-väärtus paare "nimi": "Mari". JSON on lühem ja loetavam, XML aga paindlikum (näiteks atribuudid ja nimeruumid). Mõlemat tasub osata.

Mis on JSON?¶

JSON koosneb objektidest ja massiividest. Objekt on loogeliste sulgude { } vahel olev kogum võti-väärtus paare, massiiv aga nurksulgude [ ] vahel olev loend.

Üksik objekt:

{
    "nimi": "Mari",
    "vanus": 16,
    "hinne": 4
}

Massiiv objektidest:

[
    { "nimi": "Mari", "vanus": 16, "hinne": 4 },
    { "nimi": "Jaan", "vanus": 17, "hinne": 5 }
]

JSON-is on lubatud järgmised väärtuste tüübid:

Tüüp Näide
Sõne (string) "Mari"
Arv 16, 4.5
Tõeväärtus true, false
Tühi väärtus null
Objekt { "nimi": "Mari" }
Massiiv [1, 2, 3]

Olulised erinevused C#-st:

  • Võtmed kirjutatakse alati jutumärkides: "nimi", mitte nimi.
  • Sõned on alati jutumärkides.
  • Objekti viimase paari järel ei tohi olla koma (kuigi mõned lubavad, on see vigane JSON).
  • Kommente JSON-is ei ole.

JSON nimeruum¶

.NET-is asub JSON-iga töötamiseks vajalik klass JsonSerializer nimeruumis System.Text.Json:

using System.Text.Json;

JSON-i puu kujul lugemiseks läheb vaja klass JsonDocument, mis on samuti samas nimeruumas. Päris puu objektidega (objektid ja massiivid) töötamiseks on olemas nimeruum System.Text.Json.Nodes:

using System.Text.Json;
using System.Text.Json.Nodes;

Erinevalt XML-ist ei pea JSON-i jaoks ühtegi lisapaketti paigaldama — System.Text.Json on .NET-is juba sees.

Lugemine JsonDocument-iga¶

Kõige lihtsam viis tundmatut JSON-i lugeda on JsonDocument. See laeb JSON-i mällu ja laseb väärtusi võtme järgi küsida.

Vaatleme faili opilane.json:

{
    "nimi": "Mari",
    "vanus": 16,
    "hinne": 4
}

Lugemine:

using System.IO;
using System.Text.Json;

string json = File.ReadAllText(@"C:\temp\opilane.json");

using JsonDocument doc = JsonDocument.Parse(json);
JsonElement root = doc.RootElement;

string nimi = root.GetProperty("nimi").GetString();
int vanus = root.GetProperty("vanus").GetInt32();
int hinne = root.GetProperty("hinne").GetInt32();

Console.WriteLine(nimi + " (" + vanus + ") — hinne " + hinne);

using System;
using System.IO;
using System.Text.Json;

namespace JsonApp
{
    class Program
    {
        static void Main(string[] args)
        {
            string json = File.ReadAllText(@"C:\temp\opilane.json");

            using JsonDocument doc = JsonDocument.Parse(json);
            JsonElement root = doc.RootElement;

            string nimi = root.GetProperty("nimi").GetString();
            int vanus = root.GetProperty("vanus").GetInt32();
            int hinne = root.GetProperty("hinne").GetInt32();

            Console.WriteLine(nimi + " (" + vanus + ") — hinne " + hinne);
        }
    }
}

Mõned olulised asjad selles näites:

  • JsonDocument.Parse(json) loeb JSON-teksti puuks.
  • doc.RootElement on puu juur — antud juhul objekt.
  • GetProperty("nimi") otsib välja väärtuse võtme järgi.
  • GetString() ja GetInt32() teisendavad väärtuse vastavaks C# tüübiks. Meetodid on olemas iga tüübi jaoks: GetInt32(), GetDouble(), GetBoolean(), GetString().

JsonDocument tuleb vabastada

JsonDocument implementeerib IDisposable-it, nagu IDisposable peatükist teame. Seetõttu kasutame seda using-lausega. Kui dokument on vabastatud, ei tohi selle JsonElement väärtusi enam kasutada.

Massiivi lugemine¶

Kui juur on massiiv, käime elemendid läbi meetodiga EnumerateArray():

using System.IO;
using System.Text.Json;

string json = File.ReadAllText(@"C:\temp\opilased.json");

using JsonDocument doc = JsonDocument.Parse(json);

foreach (JsonElement opilane in doc.RootElement.EnumerateArray())
{
    string nimi = opilane.GetProperty("nimi").GetString();
    int vanus = opilane.GetProperty("vanus").GetInt32();
    Console.WriteLine(nimi + " (" + vanus + ")");
}

using System;
using System.IO;
using System.Text.Json;

namespace JsonApp
{
    class Program
    {
        static void Main(string[] args)
        {
            string json = File.ReadAllText(@"C:\temp\opilased.json");

            using JsonDocument doc = JsonDocument.Parse(json);

            foreach (JsonElement opilane in doc.RootElement.EnumerateArray())
            {
                string nimi = opilane.GetProperty("nimi").GetString();
                int vanus = opilane.GetProperty("vanus").GetInt32();
                Console.WriteLine(nimi + " (" + vanus + ")");
            }
        }
    }
}

Puuduva võtme kontrollimine¶

Kui võti võib puududa, viskab GetProperty() vea. Selle asemel tasub kasutada TryGetProperty(), mis tagastab true või false:

using System.Text.Json;

using JsonDocument doc = JsonDocument.Parse(json);

if (doc.RootElement.TryGetProperty("hinne", out JsonElement hinne))
{
    Console.WriteLine("Hinne: " + hinne.GetInt32());
}
else
{
    Console.WriteLine("Hinne puudub.");
}

JSON-i kirjutamine¶

Kirjutamine JsonObject-i ja JsonArray-iga¶

Puu objektidega saab JSON-i ka ise ehitada, sarnaselt XML-i XDocument-ile. Nimeruumis System.Text.Json.Nodes on klassid JsonObject (objekt) ja JsonArray (massiiv).

using System.IO;
using System.Text.Json;
using System.Text.Json.Nodes;

JsonObject opilane = new JsonObject
{
    ["nimi"] = "Mari",
    ["vanus"] = 16,
    ["hinne"] = 4
};

string json = opilane.ToJsonString(new JsonSerializerOptions { WriteIndented = true });
File.WriteAllText(@"C:\temp\opilane.json", json);

using System.IO;
using System.Text.Json;
using System.Text.Json.Nodes;

namespace JsonApp
{
    class Program
    {
        static void Main(string[] args)
        {
            JsonObject opilane = new JsonObject
            {
                ["nimi"] = "Mari",
                ["vanus"] = 16,
                ["hinne"] = 4
            };

            string json = opilane.ToJsonString(new JsonSerializerOptions { WriteIndented = true });
            File.WriteAllText(@"C:\temp\opilane.json", json);
        }
    }
}

WriteIndented = true muudab tulemuse loetavaks — iga väärtus tuleb oma reale. Ilma selleta on JSON ühel pikal real.

Massiivi ehitamine JsonArray-iga:

using System.Text.Json.Nodes;

JsonArray opilased = new JsonArray
{
    new JsonObject { ["nimi"] = "Mari", ["vanus"] = 16 },
    new JsonObject { ["nimi"] = "Jaan", ["vanus"] = 17 }
};

string json = opilased.ToJsonString();

Serialiseerimine¶

JSON-i kõige mugavam pool on serialiseerimine: objekt muudetakse automaatselt JSON-iks. Sarnaselt XML-i XmlSerializer-ile teeb siin töö ära klass JsonSerializer — meie ei pea iga võtit ise kirjutama.

Alustame klassiga:

public class Opilane
{
    public string Nimi { get; set; }
    public int Vanus { get; set; }
    public int Hinne { get; set; }
}

Serialiseerimine ehk objekti muutmine JSON-tekstiks:

using System.IO;
using System.Text.Json;

Opilane opilane = new Opilane
{
    Nimi = "Mari",
    Vanus = 16,
    Hinne = 4
};

var options = new JsonSerializerOptions { WriteIndented = true };

string json = JsonSerializer.Serialize(opilane, options);
File.WriteAllText(@"C:\temp\opilane.json", json);

using System.IO;
using System.Text.Json;

namespace JsonApp
{
    public class Opilane
    {
        public string Nimi { get; set; }
        public int Vanus { get; set; }
        public int Hinne { get; set; }
    }

    class Program
    {
        static void Main(string[] args)
        {
            Opilane opilane = new Opilane
            {
                Nimi = "Mari",
                Vanus = 16,
                Hinne = 4
            };

            var options = new JsonSerializerOptions { WriteIndented = true };

            string json = JsonSerializer.Serialize(opilane, options);
            File.WriteAllText(@"C:\temp\opilane.json", json);
        }
    }
}

Tulemuseks on fail:

{
    "Nimi": "Mari",
    "Vanus": 16,
    "Hinne": 4
}

JsonSerializer kasutab võtmetena klasside omaduste nimesid. Serialiseerida saab ka otse voogu, mis ühendab selle peatüki streamidega:

using System.IO;
using System.Text.Json;

using (FileStream voog = File.Create(@"C:\temp\opilane.json"))
{
    JsonSerializer.Serialize(voog, opilane);
}

Võtmenimede muutmine¶

Päris maailmas kasutavad JSON-failid tavaliselt camelCase nimesid (nimi, vanus), mitte PascalCase (Nimi, Vanus). Seda saab seadistada PropertyNamingPolicy abil:

using System.Text.Json;

var options = new JsonSerializerOptions
{
    WriteIndented = true,
    PropertyNamingPolicy = JsonNamingPolicy.CamelCase
};

string json = JsonSerializer.Serialize(opilane, options);

Nüüd on tulemus:

{
    "nimi": "Mari",
    "vanus": 16,
    "hinne": 4
}

Täpsema nime saab anda atribuudiga [JsonPropertyName]:

using System.Text.Json.Serialization;

public class Opilane
{
    [JsonPropertyName("name")]
    public string Nimi { get; set; }

    [JsonPropertyName("age")]
    public int Vanus { get; set; }
}

Loendi serialiseerimine¶

Ka loendi saab korraga serialiseerida. Tulemuseks on JSON-massiiv:

using System.Collections.Generic;
using System.Text.Json;

List<Opilane> opilased = new List<Opilane>
{
    new Opilane { Nimi = "Mari", Vanus = 16, Hinne = 4 },
    new Opilane { Nimi = "Jaan", Vanus = 17, Hinne = 5 }
};

string json = JsonSerializer.Serialize(opilased, new JsonSerializerOptions { WriteIndented = true });

Tulemus:

[
    {
        "Nimi": "Mari",
        "Vanus": 16,
        "Hinne": 4
    },
    {
        "Nimi": "Jaan",
        "Vanus": 17,
        "Hinne": 5
    }
]

Deserialiseerimine¶

Deserialiseerimine on vastupidine tegevus: JSON-tekstist saab jälle C#-objekt. Kasutame sama JsonSerializer-it, aga seekord lugemiseks.

using System.IO;
using System.Text.Json;

string json = File.ReadAllText(@"C:\temp\opilane.json");

Opilane opilane = JsonSerializer.Deserialize<Opilane>(json);

Console.WriteLine(opilane.Nimi);
Console.WriteLine(opilane.Vanus);
Console.WriteLine(opilane.Hinne);

using System;
using System.IO;
using System.Text.Json;

namespace JsonApp
{
    public class Opilane
    {
        public string Nimi { get; set; }
        public int Vanus { get; set; }
        public int Hinne { get; set; }
    }

    class Program
    {
        static void Main(string[] args)
        {
            string json = File.ReadAllText(@"C:\temp\opilane.json");

            Opilane opilane = JsonSerializer.Deserialize<Opilane>(json);

            Console.WriteLine(opilane.Nimi);
            Console.WriteLine(opilane.Vanus);
            Console.WriteLine(opilane.Hinne);
        }
    }
}

Erinevalt XML-i XmlSerializer-ist ei ole vaja tulemust eraldi konverteerida — Deserialize<Opilane>() ütleb juba tüübi ära ja tagastab kohe õiget tüüpi objekti.

Tõstutundlikkus

JsonSerializer otsib võtmeid vaikimisi tõstutundlikult: "Nimi" ja "nimi" on selle jaoks erinevad. Kui JSON-is on camelCase nimed, aga klassis PascalCase, siis ilma seadistuseta väärtused ei täitu. Sel juhul lisa PropertyNameCaseInsensitive = true:

var options = new JsonSerializerOptions { PropertyNameCaseInsensitive = true };
Opilane opilane = JsonSerializer.Deserialize<Opilane>(json, options);

Loendi deserialiseerimine¶

Loendi lugemisel kasutame sama tüüpi, millega serialiseerisime — List<Opilane>:

using System.Collections.Generic;
using System.Text.Json;

string json = File.ReadAllText(@"C:\temp\opilased.json");

List<Opilane> opilased = JsonSerializer.Deserialize<List<Opilane>>(json);

foreach (Opilane opilane in opilased)
{
    Console.WriteLine(opilane.Nimi + " — hinne " + opilane.Hinne);
}

Deserialiseerida saab ka otse voost, ilma et peaksime kogu faili esmalt sõneks lugema:

using System.Collections.Generic;
using System.IO;
using System.Text.Json;

using (FileStream voog = File.OpenRead(@"C:\temp\opilased.json"))
{
    List<Opilane> opilased = JsonSerializer.Deserialize<List<Opilane>>(voog);
}

Näide: õpilaste nimekiri JSON-is¶

Paneme seni õpitu kokku. Programmis on klass Opilane, loome mitu õpilast, salvestame need JSON-i ja loeme seejärel tagasi.

using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Text.Json;

public class Opilane
{
    public string Nimi { get; set; }
    public int Vanus { get; set; }
    public int Hinne { get; set; }
}

string tee = @"C:\temp\opilased.json";

List<Opilane> opilased = new List<Opilane>
{
    new Opilane { Nimi = "Mari", Vanus = 16, Hinne = 4 },
    new Opilane { Nimi = "Jaan", Vanus = 17, Hinne = 5 },
    new Opilane { Nimi = "Kati", Vanus = 16, Hinne = 3 }
};

var options = new JsonSerializerOptions
{
    WriteIndented = true,
    PropertyNamingPolicy = JsonNamingPolicy.CamelCase
};

string json = JsonSerializer.Serialize(opilased, options);
File.WriteAllText(tee, json);

Console.WriteLine("Opilased salvestatud.");

string loetudJson = File.ReadAllText(tee);
List<Opilane> loetud = JsonSerializer.Deserialize<List<Opilane>>(
    loetudJson,
    new JsonSerializerOptions { PropertyNameCaseInsensitive = true });

Console.WriteLine("Keskmine hinne: " + loetud.Average(o => o.Hinne).ToString("F1"));

using System;
using System.Collections.Generic;
using System.IO;
using System.Linq;
using System.Text.Json;

namespace JsonApp
{
    public class Opilane
    {
        public string Nimi { get; set; }
        public int Vanus { get; set; }
        public int Hinne { get; set; }
    }

    class Program
    {
        static void Main(string[] args)
        {
            string tee = @"C:\temp\opilased.json";

            List<Opilane> opilased = new List<Opilane>
            {
                new Opilane { Nimi = "Mari", Vanus = 16, Hinne = 4 },
                new Opilane { Nimi = "Jaan", Vanus = 17, Hinne = 5 },
                new Opilane { Nimi = "Kati", Vanus = 16, Hinne = 3 }
            };

            var options = new JsonSerializerOptions
            {
                WriteIndented = true,
                PropertyNamingPolicy = JsonNamingPolicy.CamelCase
            };

            string json = JsonSerializer.Serialize(opilased, options);
            File.WriteAllText(tee, json);

            Console.WriteLine("Opilased salvestatud.");

            string loetudJson = File.ReadAllText(tee);
            List<Opilane> loetud = JsonSerializer.Deserialize<List<Opilane>>(
                loetudJson,
                new JsonSerializerOptions { PropertyNameCaseInsensitive = true });

            Console.WriteLine("Keskmine hinne: " + loetud.Average(o => o.Hinne).ToString("F1"));
        }
    }
}

Millal kasutada mida?¶

Ülesanne Sobiv vahend
Lugeda tundmatut JSON-i ja võtta üksikuid väärtusi JsonDocument
Filtreerida JSON-i sisu LINQ-iga JsonSerializer.Deserialize<List<T>>()
Ehitada JSON-i nullist käsitsi JsonObject / JsonArray
Salvestada C#-objekt JSON-i JsonSerializer.Serialize()
Lugeda JSON-ist C#-objekt JsonSerializer.Deserialize<T>()
Töötada suure JSON-failiga tükikaupa JsonSerializer.DeserializeAsync() vooga (edasijõudnutele)

Sageli tekkinud vead¶

Nimeruumi puudumine¶

// VIGA — JsonSerializer klass puudub
string json = JsonSerializer.Serialize(opilane); // Viga!

// ÕIGE
using System.Text.Json;
string json = JsonSerializer.Serialize(opilane);

Vigane JSON¶

using System.Text.Json;

// VIGA — viimase paari järel on üleliigne koma, Parse viskab JsonException
string katki = "{ \"nimi\": \"Mari\", }";
using JsonDocument doc = JsonDocument.Parse(katki); // Viga!

Tõstutundlikkuse eiramine¶

using System.Text.Json;

// JSON-is on "nimi", klassis omadus Nimi
// VIGA — vaikimisi jääb Nimi tühjaks, sest võti ei klapi
Opilane opilane = JsonSerializer.Deserialize<Opilane>(json);

// ÕIGE — lubame tõstutundlikkuse
var options = new JsonSerializerOptions { PropertyNameCaseInsensitive = true };
Opilane opilane2 = JsonSerializer.Deserialize<Opilane>(json, options);

JsonDocument-i mitte vabastamine¶

using System.Text.Json;

// VIGA — JsonDocument implementeerib IDisposable
JsonDocument doc = JsonDocument.Parse(json);

// ÕIGE — kasutame using-lauset
using JsonDocument doc2 = JsonDocument.Parse(json);

Puuduva võtme küsimine¶

using System.Text.Json;

// VIGA — kui võti "hinne" puudub, viskab GetProperty() erindi
int hinne = doc.RootElement.GetProperty("hinne").GetInt32();

// ÕIGE — kontrollime esmalt TryGetProperty-ga
if (doc.RootElement.TryGetProperty("hinne", out JsonElement h))
{
    int hinne2 = h.GetInt32();
}

Kõik meetodid ja klassid kokkuvõttes¶

Klass / meetod Tähendus
JsonDocument.Parse(json) Loeb JSON-teksti puuks
JsonDocument.RootElement JSON-i juurelement
JsonElement.GetProperty(nimi) Otsib väärtuse võtme järgi
JsonElement.TryGetProperty(nimi, out v) Otsib väärtuse, tagastab true/false
JsonElement.EnumerateArray() Käib massiivi elemendid läbi
JsonElement.GetString() Väärtus sõnena
JsonElement.GetInt32() Väärtus täisarvuna
JsonElement.GetDouble() Väärtus komaga arvuna
JsonElement.GetBoolean() Väärtus tõeväärtusena
new JsonObject { [võti] = väärtus } Loob JSON-objekti
new JsonArray { ... } Loob JSON-massiivi
JsonNode.ToJsonString(options) Muudab puu JSON-tekstiks
JsonSerializer.Serialize(objekt, options) Objekt JSON-tekstiks
JsonSerializer.Serialize(voog, objekt) Objekt JSON-ina voogu
JsonSerializer.Deserialize<T>(json) JSON-tekst objektiks tüübiga T
JsonSerializer.Deserialize<T>(voog) JSON voost objektiks

PropertyNamingPolicy = JsonNamingPolicy.CamelCase Võtmete nimed camelCase kujul
PropertyNameCaseInsensitive = true Deserialiseerimine ei arvesta tõstutundlikkust
[JsonPropertyName("nimi")] Määrab võtme nime omadusele

Harjutused¶

  1. Loo käsitsi (JsonObject-i abil) JSON-fail raamat.json, milles on pealkiri, autor ja aasta. Kirjuta programm, mis loeb selle JsonDocument-iga ja trükib väärtused konsoolile kujul Autor — Pealkiri (aasta).
  2. Loo klass Raamat omadustega Pealkiri, Autor ja Aasta. Serialiseeri List<Raamat> faili raamatud.json ning deserialiseeri see kohe tagasi ja trüki tulemus konsoolile. Kasuta WriteIndented = true, et fail oleks loetav.
  3. Loe raamatud.json failist andmed JsonSerializer.Deserialize<List<Raamat>>() abil ja kasuta LINQ-it, et leida kõik raamatud, mis on ilmunud pärast 2010. aastat. Trüki tulemus.
  4. Loo programm, mis küsib kasutajalt kordamööda raamatu pealkirja, autori ja aasta, lisab need loendisse ning serialiseerib lõpuks kogu nimekirja JSON-faili. Küsimine lõpeb, kui kasutaja jätab pealkirja tühjaks.
  5. Võta üks varasem harjutus ja salvesta samad andmed nii XML-i kui ka JSON-i. Võrdle kahte faili: milline on lühem ja milline loetavam? Kirjuta mõned tähelepanekud kommentaaridena.
