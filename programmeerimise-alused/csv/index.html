Töötamine CSV-formaadis andmetega¶

XML ja JSON on suurepärased vormingud struktuursete andmete jaoks, aga neil on üks ühine joon: need on mõeldud eelkõige programmide omavaheliseks suhtluseks. Kui aga andmeid tuleb vahetada tabelarvutusprogrammiga (Excel, Google Sheets) või need lihtsalt tabelina loetavad olla, siis on kõige levinum vorming CSV.

CSV (Comma-Separated Values) on väga lihtne tekstivorming, kus iga rida on üks kirje ja väärtused on eraldatud komadega. Sellesse vormingusse saab andmeid eksportida peaaegu iga tabelitarkvara ja andmebaas.

Selles peatükis kasutame CSV-failide lugemiseks ja kirjutamiseks CsvHelper nimelist NuGeti paketti, mis teeb musta töö ise ära — meie ei pea muretsema jutumärkide, eraldajate ega tüübiteisenduste pärast.

Mis on CSV?¶

CSV-fail on lihtne tekstifail, mille esimene rida on tavaliselt päis (header) ehk veergude nimed. Iga järgnev rida on üks andmerida ja väärtused on eraldatud eraldajaga, kõige sagedamini komaga.

id,nimi,vanus,hinne
1,Mari,16,4
2,Jaan,17,5
3,Kati,16,3

Selles näites on veerud id, nimi, vanus ja hinne ning failis on kolm õpilast.

CSV-l on mõned nipid, millega tuleb arvestada:

  • Kui väärtus ise sisaldab koma, pannakse see jutumärkidesse: "Tallinn, Kesklinn".
  • Kui väärtus sisaldab jutumärki, kirjutatakse see kahekordselt: "Nimi ""Hüüdnimi"" Perekonnanimi".
  • Tüübiteisendusi CSV ise ei tee — kõik on tekst. Arvuks muutmise eest peab hoolitsema programm.

CSV ei ole üks kindel standard

Eraldaja võib riigiti ja programmiti erineda. Eestis kasutab Excel sageli semikoolonit ; eraldajana, sest koma kasutatakse kümnendkoha märgina (näiteks 120,50). CsvHelper-iga saab eraldaja ise määrata.

CsvHelper pakett¶

CsvHelper ei ole .NET-is vaikimisi sees, vaid tuleb eraldi paigaldada NuGeti paketina.

  • Visual Studio-s: Tools → NuGet Package Manager → Manage NuGet Packages for Solution, otsi CsvHelper ja paigalda.
  • Konsoolis: dotnet add package CsvHelper

Pärast paigaldamist tuleb programmi lisada nimeruumid. CsvHelper vajab arvude ja kuupäevade teisendamiseks ka kultuuri (CultureInfo) — selleks kasutame vaikimisi InvariantCulture, mis tähendab eraldajana punkti:

using CsvHelper;
using CsvHelper.Configuration;
using System.Globalization;

Miks CultureInfo vajalik on

CsvHelper peab teadma, kuidas teksti arvuks teisendada. Kas "120.50" on sada kakskümmend koma viis või hoopis 12050? Selle määrab kultuur. InvariantCulture kasutab punkti kümnendkohana, eestikeelne CultureInfo.GetCultureInfo("et-EE") aga koma.

Deserialiseerimine — lugemine klassidesse¶

Deserialiseerimine tähendab CSV-ridade muutmist C#-objektideks. Selleks kirjeldame kõigepealt klassi, mille omadused vastavad CSV veergudele:

public class Opilane
{
    public int Id { get; set; }
    public string Nimi { get; set; }
    public int Vanus { get; set; }
    public int Hinne { get; set; }
}

CsvHelper ühendab veerupealkirjad omaduste nimedega automaatselt. Lugemiseks avame faili StreamReader-iga ja anname selle CsvReader-ile. Kasutame using-lauset, sest mõlemad klassid implementeerivad IDisposable-it, nagu IDisposable peatükist teame.

using System.Collections.Generic;
using System.Globalization;
using System.IO;
using System.Linq;
using CsvHelper;

using (var reader = new StreamReader(@"C:\temp\opilased.csv"))
using (var csv = new CsvReader(reader, CultureInfo.InvariantCulture))
{
    List<Opilane> opilased = csv.GetRecords<Opilane>().ToList();

    foreach (Opilane opilane in opilased)
    {
        Console.WriteLine(opilane.Nimi + " (" + opilane.Vanus + ")");
    }
}

using System;
using System.Collections.Generic;
using System.Globalization;
using System.IO;
using System.Linq;
using CsvHelper;

namespace CsvApp
{
    public class Opilane
    {
        public int Id { get; set; }
        public string Nimi { get; set; }
        public int Vanus { get; set; }
        public int Hinne { get; set; }
    }

    class Program
    {
        static void Main(string[] args)
        {
            using (var reader = new StreamReader(@"C:\temp\opilased.csv"))
            using (var csv = new CsvReader(reader, CultureInfo.InvariantCulture))
            {
                List<Opilane> opilased = csv.GetRecords<Opilane>().ToList();

                foreach (Opilane opilane in opilased)
                {
                    Console.WriteLine(opilane.Nimi + " (" + opilane.Vanus + ")");
                }
            }
        }
    }
}

Olulised asjad:

  • GetRecords<Opilane>() loeb kõik read ja teeb neist Opilane objektid.
  • GetRecords() tagastab laisa loendi — read loetakse alles siis, kui neid päritakse. Seetõttu kutsume kohe ToList(), et andmed oleksid enne using-ploki lõppu käes.
  • CsvReader teisendab tüübid ise: tekstist saab int, decimal, DateTime jne.

Lugemine rea kaupa, ilma klassita¶

Kui klass pole vaja või veerge on ettearvamatult palju, saab lugeda ka rida-realt. Read() liigub järgmisele reale ja GetField() annab väärtuse kas veeru nime või indeksi järgi:

using System.Globalization;
using System.IO;
using CsvHelper;

using (var reader = new StreamReader(@"C:\temp\opilased.csv"))
using (var csv = new CsvReader(reader, CultureInfo.InvariantCulture))
{
    csv.Read();
    csv.ReadHeader();

    while (csv.Read())
    {
        int id = csv.GetField<int>("id");
        string nimi = csv.GetField("nimi");
        Console.WriteLine(id + " — " + nimi);
    }
}

Erinev eraldaja ja kultuur¶

Kui fail kasutab semikoolonit ja eestikeelseid kümnendkohti, seadistame selle CsvConfiguration-iga:

using System.Globalization;
using System.IO;
using CsvHelper;
using CsvHelper.Configuration;

var config = new CsvConfiguration(CultureInfo.GetCultureInfo("et-EE"))
{
    Delimiter = ";"
};

using (var reader = new StreamReader(@"C:\temp\opilased.csv"))
using (var csv = new CsvReader(reader, config))
{
    var opilased = csv.GetRecords<Opilane>().ToList();
}

Serialiseerimine — kirjutamine klassidest¶

Serialiseerimine on vastupidine tegevus: C#-objektidest tehakse CSV-text. CsvHelperis piisab meetodist WriteRecords(), mis kirjutab automaatselt ka päiserea.

using System.Collections.Generic;
using System.Globalization;
using System.IO;
using CsvHelper;

List<Opilane> opilased = new List<Opilane>
{
    new Opilane { Id = 1, Nimi = "Mari", Vanus = 16, Hinne = 4 },
    new Opilane { Id = 2, Nimi = "Jaan", Vanus = 17, Hinne = 5 }
};

using (var writer = new StreamWriter(@"C:\temp\opilased.csv"))
using (var csv = new CsvWriter(writer, CultureInfo.InvariantCulture))
{
    csv.WriteRecords(opilased);
}

using System.Globalization;
using System.IO;
using CsvHelper;

namespace CsvApp
{
    public class Opilane
    {
        public int Id { get; set; }
        public string Nimi { get; set; }
        public int Vanus { get; set; }
        public int Hinne { get; set; }
    }

    class Program
    {
        static void Main(string[] args)
        {
            List<Opilane> opilased = new List<Opilane>
            {
                new Opilane { Id = 1, Nimi = "Mari", Vanus = 16, Hinne = 4 },
                new Opilane { Id = 2, Nimi = "Jaan", Vanus = 17, Hinne = 5 }

Tulemuseks on fail:

Id,Nimi,Vanus,Hinne
1,Mari,16,4
2,Jaan,17,5

Päiseks saavad klasside omaduste nimed (Id, Nimi, ...). CsvHelper lisab jutumärgid automaatselt sinna, kus neid vaja on.

Kirjutamine rea kaupa¶

Vajadusel saab ridu kirjutada ka käsitsi meetoditega WriteField() ja NextRecord():

using System.Globalization;
using System.IO;
using CsvHelper;

using (var writer = new StreamWriter(@"C:\temp\nimed.csv"))
using (var csv = new CsvWriter(writer, CultureInfo.InvariantCulture))
{
    csv.WriteField("id");
    csv.WriteField("nimi");
    csv.NextRecord();

    csv.WriteField(1);
    csv.WriteField("Mari");
    csv.NextRecord();
}

Veergude nimede ja järjekorra määramine¶

Vaikimisi kasutab CsvHelper omaduste nimesid ja nende järjekorda. Päris andmetes on pealkirjad aga tihti väiketähtedega, tühikutega või hoopis teise keeles. Seda saab määrata kahel viisil.

Atribuutidega¶

Kõige lihtsam on panna omaduse ette [Name] atribuut nimeruumist CsvHelper.Configuration.Attributes:

using CsvHelper.Configuration.Attributes;

public class Opilane
{
    [Name("id")]
    public int Id { get; set; }

    [Name("nimi")]
    public string Nimi { get; set; }

    [Name("vanus")]
    public int Vanus { get; set; }
}

Nüüd on veerupealkirjad väiketähtedega ja vastavad täpselt CSV-le.

ClassMap klassiga¶

Suuremate projektide puhul hoitakse vastendusi eraldi ClassMap-klassis. See hoiab andmeklassi puhtana:

using CsvHelper.Configuration;

public sealed class OpilaneMap : ClassMap<Opilane>
{
    public OpilaneMap()
    {
        Map(m => m.Id).Name("id");
        Map(m => m.Nimi).Name("nimi");
        Map(m => m.Vanus).Name("vanus").Default(0);
        Map(m => m.Hinne).Name("hinne").Optional();
    }
}

Enne lugemist või kirjutamist tuleb vastendus registreerida:

using (var csv = new CsvReader(reader, CultureInfo.InvariantCulture))
{
    csv.Context.RegisterClassMap<OpilaneMap>();
    var opilased = csv.GetRecords<Opilane>().ToList();
}

Näide: võlglaste leidmine ja uue CSV koostamine¶

Vaatame päris elulist ülesannet. Sisendfailis maksed.csv on igal real kliendi id, nimi, tehtud maksete summa ja esitatud arvete summa:

id,kliendi_nimi,maksete_summa,arvete_summa
1,Mari Maasikas,120.50,200.00
2,Jaan Juurikas,300.00,150.00
3,Kati Kask,50.00,90.00

Soovime välja kirjutada uue CSV, kus on ainult võlglased: id, kliendi nimi ja võlgnevus (arvete summa miinus maksete summa). Kellel arved on makstud, seda väljundisse ei tule.

Kliendi võlgnevus on arvete_summa - maksete_summa. Vaatame andmeid:

id nimi maksete summa arvete summa võlgnevus
1 Mari Maasikas 120.50 200.00 79.50
2 Jaan Juurikas 300.00 150.00 -150.00 (ei ole võlglane)
3 Kati Kask 50.00 90.00 40.00

Väljundfailiks peab saama:

id,kliendi_nimi,volgnevus
1,Mari Maasikas,79.50
3,Kati Kask,40.00

Loome kaks andmeklassi — üks sisendi, teine väljundi jaoks:

using CsvHelper.Configuration.Attributes;

public class KliendiMaksed
{
    [Name("id")]
    public int Id { get; set; }

    [Name("kliendi_nimi")]
    public string KliendiNimi { get; set; }

    [Name("maksete_summa")]
    public decimal MakseteSumma { get; set; }

    [Name("arvete_summa")]
    public decimal ArveteSumma { get; set; }
}

public class KliendiVolg
{
    [Name("id")]
    public int Id { get; set; }

    [Name("kliendi_nimi")]
    public string KliendiNimi { get; set; }

    [Name("volgnevus")]
    public decimal Volgnevus { get; set; }
}

Kogu programm:

using System.Collections.Generic;
using System.Globalization;
using System.IO;
using System.Linq;
using CsvHelper;
using CsvHelper.Configuration.Attributes;

using (var reader = new StreamReader(@"C:\temp\maksed.csv"))
using (var csv = new CsvReader(reader, CultureInfo.InvariantCulture))
{
    List<KliendiMaksed> read = csv.GetRecords<KliendiMaksed>().ToList();

    List<KliendiVolg> volglased = read
        .Select(r => new KliendiVolg
        {
            Id = r.Id,
            KliendiNimi = r.KliendiNimi,
            Volgnevus = r.ArveteSumma - r.MakseteSumma
        })
        .Where(v => v.Volgnevus > 0)
        .ToList();

    using (var writer = new StreamWriter(@"C:\temp\volglased.csv"))
    using (var csvWriter = new CsvWriter(writer, CultureInfo.InvariantCulture))
    {
        csvWriter.WriteRecords(volglased);
    }

    Console.WriteLine("Võlglasi: " + volglased.Count);
}

using System.IO;
using System.Linq;
using CsvHelper;
using CsvHelper.Configuration.Attributes;

namespace CsvApp
{
    public class KliendiMaksed

        public string KliendiNimi { get; set; }

    {

        {

            using (var csv = new CsvReader(reader, CultureInfo.InvariantCulture))
            {

Mida programm teeb, samm-sammult:

  1. Loeb sisendfaili GetRecords<KliendiMaksed>()-iga tervikuna sisse.
  2. Arvutab iga kliendi kohta võlgnevuse ja koostab uued KliendiVolg objektid — seda teeb LINQ Select(), mida tunneme LINQ peatükist.
  3. Jätab Where(v => v.Volgnevus > 0) abil alles ainult need, kelle võlgnevus on suurem kui null.
  4. Kirjutab tulemuse WriteRecords()-iga uude CSV-faili, kus on täpselt soovitud veerud.

Nii saame ühe CSV andmevoo teisendada teiseks, huvipakkuva osa välja filtreerida ja tulemuse uude faili kirjutada.

Sageli tekkinud vead¶

CsvHelper pakett puudub¶

// VIGA — CsvReader klass puudub, kui pakett pole paigaldatud
using CsvReader lugeja = ...; // Viga!

// ÕIGE — paigalda pakett ja lisa nimeruumid
using CsvHelper;
using System.Globalization;

CultureInfo puudumine¶

using CsvHelper;

// VIGA — CsvHelper nõuab kultuuri, muidu viskab erindi
var csv = new CsvReader(reader); // Viga!

// ÕIGE
var csv2 = new CsvReader(reader, CultureInfo.InvariantCulture);

GetRecords() tulemus kaob using-plokist väljumisel¶

using System.IO;

List<Opilane> opilased;

using (var csv = new CsvReader(new StreamReader(tee), CultureInfo.InvariantCulture))
{
    opilased = csv.GetRecords<Opilane>().ToList(); // ToList() on vajalik!
}

// kui ToList() puudub, on opilased tühi või viskab vea
foreach (Opilane opilane in opilased) { }

// VIGA — CSV-s on "kliendi nimi", aga omadus on KliendiNimi
public class Katki

    public string KliendiNimi { get; set; }

// ÕIGE — kasuta [Name] atribuuti täpse pealkirjaga

    [Name("kliendi nimi")]
    public string KliendiNimi { get; set; }

Vale eraldaja¶

using CsvHelper;
using CsvHelper.Configuration;

// VIGA — fail kasutab semikoolonit, aga ootame koma
var csv = new CsvReader(reader, CultureInfo.InvariantCulture);

// ÕIGE — määrame eraldaja
var config = new CsvConfiguration(CultureInfo.InvariantCulture) { Delimiter = ";" };
var csv2 = new CsvReader(reader, config);

Kõik meetodid ja klassid kokkuvõttes¶

Klass / meetod Tähendus
new CsvReader(reader, culture) Loob CSV-lugeja
new CsvWriter(writer, culture) Loob CSV-kirjutaja
new CsvConfiguration(culture) Seadistus (eraldaja, kultuur jne)
CsvConfiguration.Delimiter Veergude eraldaja, vaikimisi ,
csv.GetRecords<T>() Loeb kõik read objektideks (laisalt)
csv.GetRecord<T>() Loeb ühe rea objektiks
csv.Read() Liigub järgmisele reale
csv.ReadHeader() Loeb päiserea
csv.GetField(nimi) Väärtus ühe veeru järgi
csv.GetField<T>(nimi) Väärtus teisendatud tüübiga T
csv.WriteRecords<T>(loend) Kirjutab objektid CSV-ina
csv.WriteField(väärtus) Kirjutab ühe välja
csv.NextRecord() Liigub järgmise rea peale
csv.Context.RegisterClassMap<M>() Registreerib ClassMap vastenduse
[Name("nimi")] Määrab veeru pealkirja omadusele
ClassMap<T> Eraldi klass veergude vastendamiseks

Harjutused¶

  1. Loo käsitsi tekstifail opilased.csv, kus on veerud id,nimi,vanus,hinne ja vähemalt kolm õpilast. Kirjuta programm, mis loeb selle CsvHelper-iga sisse ja trükib iga õpilase nime ja hinde.
  2. Loo klass Raamat omadustega Pealkiri, Autor ja Aasta. Kirjuta programm, mis loob paar raamatut ja salvestab need raamatud.csv faili. Seejärel loe sama fail tagasi ja trüki tulemus konsoolile.
  3. Loe opilased.csv failist andmed sisse ja kirjuta uus CSV, kuhu lähevad ainult need õpilased, kelle hinne on vähemalt 4. Kasuta LINQ-it.
  4. Loo sisendfail maksed.csv (id, kliendi_nimi, maksete_summa, arvete_summa) vähemalt nelja kliendiga. Kirjuta programm, mis väljastab uue CSV faili, kus on ainult võlglased kujul id,kliendi_nimi,volgnevus — nagu peatüki näites, aga lisa ka juht, kus võlgnevus on täpselt null (see ei ole võlglane).
  5. Loe sama maksed.csv faili, aga kus eraldajaks on semikoolon ja kümnendkohtadeks koma (näiteks 120,50). Seadista CsvConfiguration eestikeelse kultuuriga ja veendu, et programm loeb summad õigesti.
  6. Sorteeri harjutuse 3 tulemus õpilaste hinde järgi kahanevas järjekorras enne uude faili kirjutamist.
