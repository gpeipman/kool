Võrdlused¶

Programmeerimisel peame pidevalt andmeid võrdlema: kas number on suurem kui teine? Kas tekst kattub oodatuga? Kas kuupäev on möödunud? Võrdluse tulemus on alati tõeväärtus — kas true (tõene) või false (väär). just neid tõeväärtusi kasutame hiljem if lausetes otsuste tegemiseks.

Arvude võrdlemine¶

Arve võrdlemiseks on C#-is kuus operaatorit.

Operaator Tähendus Näide Tulemus
== võrdub 5 == 5 true
!= ei võrdu 5 != 3 true
< väiksem kui 3 < 5 true
> suurem kui 5 > 3 true
<= väiksem või võrdne 5 <= 5 true
>= suurem või võrdne 3 >= 5 false 
namespace ComparisonApp;

class Program
{
    static void Main(string[] args)
    {
        int vanus = 17;
        bool kasOnVanemKui16 = vanus > 16;
        bool kasOnTäisealine = vanus >= 18;
        bool kasOn17 = vanus == 17;

        Console.WriteLine("Vanem kui 16: " + kasOnVanemKui16);   // true
        Console.WriteLine("Täisealine: " + kasOnTäisealine);      // false
        Console.WriteLine("On 17: " + kasOn17);                    // true
    }
}

Sage algaja viga: = vs ==

Üks võrdusmärk = annab muutujale väärtuse. Kaks võrdusmärki == võrdleb. Need on kaks täiesti erinevat asja. 

int x = 5;     // annab väärtuse — see on õige
// if (x = 5)  // VIGA — siin ei võrrelda, vaid annad väärtust
if (x == 5)    // õige — võrdled

Igapäevaelu näited¶

// Bussipilet
int piletihind = 2;
bool kasTasuta = piletihind == 0;       // false
bool kasOdav = piletihind < 3;          // true

// Koolihinne
int hinne = 4;
bool kasHeaHinne = hinne >= 5;          // false
bool kasMiinimum = hinne >= 1;          // true

Stringide võrdlemine¶

Stringe võrreldakse tähthaaval. Tähed reastatakse tähestiku järjekorras: A on väiksem kui B, a on väiksem kui b jne. Suurtäht ja väiketäht on erinevad — "Mari" ja "mari" ei ole võrdsed.

namespace StringComparisonApp;

class Program
{
    static void Main(string[] args)
    {
        string kasutajanimi = "mari";
        bool kasOnAdmin = kasutajanimi == "admin";     // false
        bool kasOnMari = kasutajanimi == "mari";        // true
        bool kasOnMituhteist = "mari" == "Mari";        // false — erinevad tähed!

        Console.WriteLine("Admin: " + kasOnAdmin);      // false
        Console.WriteLine("Mari: " + kasOnMari);         // true
        Console.WriteLine("mari == Mari: " + kasOnMituhteist); // false
    }
}

Igapäevaelu näited¶

// WiFi nimi
string wifiNimi = "KoduWiFi";
bool kasKoduWifi = wifiNimi == "KoduWiFi";      // true
bool kasLahti = wifiNimi != "Mituhteist";        // true

// пароль kontroll
string parool = "kala123";
bool kasParoolOnPikk = parool.Length >= 6;        // true

Meetodid stringidega

string tüübil on kasulikke meetodeid: - .Length — stringi pikkus (tähemärkide arv) - .ToLower() / .ToUpper() — muuda kõik tähed väiketähtedeks/suurteks - .Contains("otsitav") — kas string sisaldab otsitavat sõna

Boolide võrdlemine¶

Boolid (true ja false) saab samuti võrrelda, kuigi enamasti piisab lihtsalt muutuja kasutamisest.

namespace BoolComparisonApp;

class Program
{
    static void Main(string[] args)
    {
        bool kasTänaOnTööpäev = true;
        bool kasOnNädalavahetus = false;

        // Need kaks rida annavad sama tulemuse
        bool kasPeabMinemaA = kasTänaOnTööpäev == true;
        bool kasPeabMinemaB = kasTänaOnTööpäev;

        Console.WriteLine(kasPeabMinemaA);  // true
        Console.WriteLine(kasPeabMinemaB);  // true

        // Võrdlus vale väärtusega
        bool kasOnPuhkus = kasOnNädalavahetus == true; // false

        // Pööramine operaatoriga !
        bool kasEiPeaMinema = !kasTänaOnTööpäev;       // false

        Console.WriteLine(kasOnPuhkus);     // false
        Console.WriteLine(kasEiPeaMinema);  // false
    }
}

Boole ei pea võrdlema

if (kasOnAdmin == true) on õige, kuid if (kasOnAdmin) on lühem ja loetavam. Mõlemad töötavad samamoodi. Võrdlemist vajad siis, kui tahad kontrollida false väärtust: if (kasOnAdmin == false) või lühemalt if (!kasOnAdmin).

Kuupäevade võrdlemine¶

DateTime tüüp toetab kõiki võrdlusoperaatoreid. See on kasulik, kui tahad teada, kas kuupäev on möödunud, tulemas või kattub.

namespace DateComparisonApp;

class Program
{
    static void Main(string[] args)
    {
        DateTime synnipäev = new DateTime(2008, 5, 15);
        DateTime täna = DateTime.Now;

        bool kasSünnipäevOnMöödas = täna > synnipäev;
        bool kasSünnipäevOnTäna = täna.Date == synnipäev.Date;

        Console.WriteLine("Sünnipäev möödas: " + kasSünnipäevOnMöödas); // true
        Console.WriteLine("Sünnipäev täna: " + kasSünnipäevOnTäna);       // false (tõenäoliselt)

        // Kontrolli kas kuupäev on tulevikus
        DateTime eksami = new DateTime(2026, 12, 20);
        bool kasEksamiEes = eksami > DateTime.Now;
        Console.WriteLine("Eksami ees: " + kasEksamiEes); // true
    }
}

Igapäevaelu näited¶

// Sooduspakkumine
DateTime pakkumiseLõpp = new DateTime(2026, 12, 31);
bool kasPakkumineKehtib = DateTime.Now <= pakkumiseLõpp;

// Laenutuse tähtaeg
DateTime laenutus = new DateTime(2026, 9, 1);
DateTime tänane = DateTime.Now;
int päeviAega = 14 - (tänane - laenutus).Days;
bool kasHilinenud = tänane > laenutus.AddDays(14);

Loogilised operaatorid¶

Tihti peame kontrollima mitut tingimust korraga. Selleks on kolm loogilist operaatorit.

Operaator Tähendus Selgitus
&& JA (AND) Mõlemad peavad olema tõesed
\|\| VÕI (OR) Üks peab olema tõene
! MITTE (NOT) Pöörab tõeväärtuse ümber 
namespace LogicalApp;

class Program
{
    static void Main(string[] args)
    {
        int vanus = 17;
        bool kasOnIDKaart = true;

        // JA — mõlemad peavad olema tõesed
        bool kasSaanHääletada = vanus >= 18 && kasOnIDKaart;
        Console.WriteLine("Hääletada saab: " + kasSaanHääletada); // false (vanus < 18)

        // VÕI — üks peab olema tõene
        bool kasVajanLuba = vanus < 18 || !kasOnIDKaart;
        Console.WriteLine("Luba vaja: " + kasVajanLuba); // true (vanus < 18)

        // MITTE — pöörab väärtuse ümber
        bool kasEiOleTäisealine = !(vanus >= 18);
        Console.WriteLine("Ei ole täisealine: " + kasEiOleTäisealine); // true
    }
}

Igapäevaelu näited¶

// Bussisõit — soodushind alla 18 või üliõpilasele
int vanus = 16;
bool kasOnÜliõpilane = false;
bool kasSoodushind = vanus < 18 || kasOnÜliõpilane; // true

// Turvavöö — kõik peavad olema kinnitatud
bool esiistmelKinnitatud = true;
bool tagaistmelKinnitatud = false;
bool kasKõikKinnitatud = esiistmelKinnitatud && tagaistmelKinnitatud; // false

// ligipääs — admin ja süsteem peavad mõlemad olema
bool kasAdmin = true;
bool kasSüsteem = false;
bool kasLubatud = kasAdmin && kasSüsteem; // false

Järjestus ja sulud

Loogilistel operaatoritel on oma eelisjärjekord: ! enne && enne ||. Kui pole kindel, kasuta sulge. 

// Sama tulemus, aga selgem
bool a = vanus >= 18 && kasOnIDKaart;
bool b = (vanus >= 18) && (kasOnIDKaart);

Harjutused¶

  1. Kirjuta programm, mis kontrollib, kas number on positiivne (> 0), negatiivne (< 0) või null. Küsi number kasutajalt.
  2. Kirjuta programm, mis kontrollib, kas kasutaja on sisselogitud JA kas tal on admini õigused. Kasuta kahte booli muutujat.
  3. Kirjuta programm, mis võrdleb kahe õpilase hindeid. Kellel on kõrgem keskmine? Kas mõlemal on miinimumhinne 3?
