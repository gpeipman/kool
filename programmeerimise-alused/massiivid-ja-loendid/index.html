Massiivid ja loendid¶

Seni oleme hoidnud iga väärtuse eraldi muutujas. Aga mis siis, kui peame hoidma 20 õpilase nime või 50 toote hinda? Üksikute muutujate loomine oleks tüütu ja ebapraktiline. Selleks ongi massiivid ja loendid — need võimaldavad hoida mitut väärtust ühes muutujas.

Massiivid¶

Massiiv on fikseeritud suurusega kogum, kuhu saame salvestada mitu ühest tüüpi väärtust. Massiivi suurust ei saa peale loomist muuta.

Massiivi loomine¶

namespace ArrayApp;

class Program
{
    static void Main(string[] args)
    {
        // Loome massiivi, mis mahutab 5 täisarvu
        int[] hinded = new int[5];

        // Anname väärtused indeksite kaupa (algab nullist!)
        hinded[0] = 5;
        hinded[1] = 4;
        hinded[2] = 3;
        hinded[3] = 5;
        hinded[4] = 4;

        // Või lühem variant — anname väärtused kohe
        string[] toidud = { "Pizza", "Pasta", "Salat", "Supp" };

        // Või pikem variant
        double[] hinnad = new double[] { 1.99, 4.50, 0.75, 12.99 };

        Console.WriteLine("Esimene hind: " + hinnad[0]);  // 1.99
        Console.WriteLine("Kolmas toit: " + toidud[2]);    // Salat
    }
}

Indeksid algavad nullist

Esimene element on indeksil 0, mitte 1. See on kõige levinum algaja viga. 

string[] puuviljad = { "Õun", "Banaan", "Apelsin" };
// puuviljad[0] → "Õun"
// puuviljad[1] → "Banaan"
// puuviljad[2] → "Apelsin"
// puuviljad[3] → VIGA! IndexOutOfRangeException

Massiivi pikkus¶

Massiivi elementide arvu saame teada .Length omadusega:

int[] numbrid = { 10, 20, 30, 40, 50 };
Console.WriteLine("Massiivis on " + numbrid.Length + " elementi."); // 5

Igapäevaelu näited¶

// Nädalapäevad
string[] nadalapaevad = { "Esmaspäev", "Teisipäev", "Kolmapäev", "Neljapäev", "Reede", "Laupäev", "Pühapäev" };
Console.WriteLine("Täna on: " + nadalapaevad[0]); // Esmaspäev
Console.WriteLine("Nädala viimane päev: " + nadalapaevad[6]); // Pühapäev

// Klassi hinnete keskmine
int[] matemaatikaHinded = { 5, 4, 3, 5, 4, 5, 4 };
int summa = matemaatikaHinded[0] + matemaatikaHinded[1] + matemaatikaHinded[2] + matemaatikaHinded[3] + matemaatikaHinded[4] + matemaatikaHinded[5] + matemaatikaHinded[6];
double keskmine = (double)summa / matemaatikaHinded.Length;
Console.WriteLine("Keskmine hinne: " + keskmine); // 4.28...

Tsüklid tulevad hiljem

Hinnete summa arvutamisel kirjutasime iga indeksi käsitsi. Hiljem õpime tsükleid, mis teevad selle palju lühemaks.

Massiivi muutmine¶

Kuna massiivi suurus on fikseeritud, siis elemente saame muuta, aga uut elementi lisada ei saa.

int[] numbrid = { 1, 2, 3, 4, 5 };
numbrid[2] = 99;    // muuda kolmandat elementi
Console.WriteLine(numbrid[2]); // 99

// numbrid[5] = 6; // VIGA! IndexOutOfRangeException — massiiv on ainult 5 pikk

Loendid (List)¶

Loend on muudetava suurusega kogum. Erinevalt massiivist saame loendisse elemente juurde lisada ja neid eemaldada. Enamasti on loend praktilisem kui massiiv.

Loendi kasutamiseks peame lisama using System.Collections.Generic; rea programmi ülaossa.

Loendi loomine¶

using System.Collections.Generic;

namespace ListApp;

class Program
{
    static void Main(string[] args)
    {
        // Tühi loend
        List<string> ostukorv = new List<string>();

        // Või algväärtustatud loend
        List<int> numbrid = new List<int> { 10, 20, 30 };

        Console.WriteLine("Loendis on " + numbrid.Count + " elementi."); // 3
    }
}

.Count vs .Length

Massiiv kasutab .Length, loend kasutab .Count. Mõlemad annavad elementide arvu.

Elementide lisamine¶

using System.Collections.Generic;

namespace ListAddApp;

class Program
{
    static void Main(string[] args)
    {
        List<string> sõbrad = new List<string>();

        // Lisa üks element lõppu
        sõbrad.Add("Mari");
        sõbrad.Add("Jaan");
        sõbrad.Add("Kati");

        Console.WriteLine("Sõpru on: " + sõbrad.Count); // 3

        // Lisa konkreetsele kohale
        sõbrad.Insert(1, "Peeter");
        // Nüüd on: Mari, Peeter, Jaan, Kati

        Console.WriteLine("Teine sõber: " + sõbrad[1]); // Peeter
    }
}

Elementide eemaldamine¶

List<string> toidud = new List<string> { "Pizza", "Pasta", "Salat", "Supp" };

// Eemalda nime järgi (esimene vastav leitud element)
toidud.Remove("Pasta");

// Eemalda indeksi järgi
toidud.RemoveAt(0); // eemaldab esimese elemendi ("Pizza")

// Tühjenda kogu loend
toidud.Clear();

Otsimine ja kontrollimine¶

List<string> linnad = new List<string> { "Tallinn", "Tartu", "Pärnu", "Narva" };

// Kas element on olemas?
bool onTallinn = linnad.Contains("Tallinn");       // true
bool onKohtlaJärve = linnad.Contains("Kohtla-Järve"); // false

// Millisel indeksil on element?
int indeks = linnad.IndexOf("Pärnu");              // 2

// Mitu elementi on?
int arv = linnad.Count;                             // 4

Igapäevaelu näited¶

// Ostukorv — kaks paralleelset loendit
List<string> tooted = new List<string>();
List<double> hinnad = new List<double>();

tooted.Add("Piim");     hinnad.Add(1.29);
tooted.Add("Leib");     hinnad.Add(2.49);
tooted.Add("Munad");    hinnad.Add(3.99);

Console.WriteLine("Ostukorv:");
Console.WriteLine("  " + tooted[0] + " — " + hinnad[0] + "€");
Console.WriteLine("  " + tooted[1] + " — " + hinnad[1] + "€");
Console.WriteLine("  " + tooted[2] + " — " + hinnad[2] + "€");

// Kõikide hindade summa
double koguSumma = hinnad[0] + hinnad[1] + hinnad[2];
Console.WriteLine("Kokku: " + koguSumma + "€");

// Sõnumite nimekiri
List<string> sõnumid = new List<string>();
sõnumid.Add("Tere!");
sõnumid.Add("Kuidas läheb?");
sõnumid.Add("Näeme homme!");

Console.WriteLine("Sõnumeid: " + sõnumid.Count);
Console.WriteLine("Esimene: " + sõnumid[0]);
Console.WriteLine("Viimane: " + sõnumid[2]);

Massiiv vs loend — millal kumbagi?¶

Omadus Massiiv ([]) Loend (List<T>)
Suurus Fikseeritud Muudetav
Lisamine Ei saa Saab .Add()
Eemaldamine Ei saa Saab .Remove()
Kiirus Natuke kiirem Natuke aeglasem
Kasutus Kui suurus on teada Kui suurus võib muutuda

Reegel pöialt

Kui tead ette, mitu elementi on vaja, kasuta massiivi. Kui elementide arv võib töö ajal muutuda, kasuta loendit.

Sageli tekkinud vead¶

Indeksi piirid¶

int[] numbrid = { 1, 2, 3 };
// numbrid[3] = 4; // VIGA — max indeks on 2
// numbrid[-1];    // VIGA — negatiivsed indeksid ei tööta

Tühja loendiga töötamine¶

List<string> nimed = new List<string>();
// nimed[0]; // VIGA — IndexOutOfRangeException, loend on tühi
Console.WriteLine(nimed.Count); // 0 — kontrolli alati enne

Massiivi suuruse unustamine¶

// VIGA — unustasid suuruse
// int[] valed = new int[]; 

// ÕIGE
int[] õige = new int[5];       // 5 elementi
int[] kaÕige = { 1, 2, 3 };   // 3 elementi, suurus automaatne

Harjutused¶

  1. Loo massiiv viie lemmikfilmi nimega. Kuva kõik filmid ekraanile nummerdatult, kasutades iga indeksit eraldi (1. Film, 2. Film, ...).
  2. Loo loend sõpradest. Lisa kolm sõpra, seejärel eemalda üks ja kuva lõplik nimekiri koos arvuga.
  3. Loo massiiv viie klassikaaslase nimega. Kuva esimene, kolmas ja viimane nimi. Seejärel muuda teine nimi uue nimega ja kuva muudetud massiiv.
