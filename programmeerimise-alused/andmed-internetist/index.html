Andmed internetist¶

Seni oleme andmeid lugenud kettalt: failidest, XML-ist, JSON-ist ja CSV-st. Aga tänapäeval asub suur osa huvitavatest andmetest hoopis internetis. Ilmateade, valuutakursid, börsiandmed, uudisteocket — kõike seda saab programm küsida otse veebist.

Andmete küsimine internetist käib veebiteenuse ehk API (Application Programming Interface) kaudu. Programm saadab aadressile päringu ja teenus vastab andmetega, väga sageli just JSON-kujul.

Selles peatükis õpime, kuidas programm toob internetist andmeid ja teeb neist C#-objektid.

Internet kui andmeallikas¶

Veebiteenus on nagu tavaline veebileht, aga selle asemel et tagastada ilusat HTML-lehte, tagastab see tooreid andmeid — tavaliselt JSON-i. Iga andmekogum on oma aadressi (URL) taga.

Näiteks teenus jsonplaceholder.typicode.com, mida hästi õppimiseks kasutame, pakub testandmeid:

Aadress Mida tagastab
https://jsonplaceholder.typicode.com/users Massiiv kasutajatest
https://jsonplaceholder.typicode.com/users/1 Üks kindel kasutaja
https://jsonplaceholder.typicode.com/posts Massiiv postitustest
https://jsonplaceholder.typicode.com/todos Massiiv ülesannetest

Kui avad sellise aadressi brauseris, näed tavalist JSON-teksti. Meie ülesanne on sama tekst programmi sisse lugeda.

Nende aadresside juures on oluline algus https:// ehk protokoll, mille kaudu andmed liiguvad. Vaikimisi kasutame GET-päringut — see on kõige lihtsam päring, mis lihtsalt küsib andmeid, muutmata midagi.

HttpClient klass¶

Internetist andmete küsimiseks on .NET-is klass HttpClient, mis asub nimeruumis System.Net.Http. HttpClient implementeerib IDisposable-it, nagu IDisposable peatükist teame, seega kasutame seda using-lausega.

using System.Net.Http;

Kliendi loomine

Väikestes programmides võib HttpClient-i luua iga päringu jaoks. Päris rakendustes aga soovitatakse hoida ühte püsivat HttpClient-i ja kasutada seda kogu programmi jooksul — nii on päringud kiiremad.

Asünkroonne kood — async ja await¶

Enne kui päringu teeme, tuleb selgeks saada üks uus mõiste. Internetist vastuse ootamine võtab aega — tavaliselt mõnikümmend kuni mõnisada millisekundit. Selle aja jooksul ei taha me, et programm lihtsalt kinni jääks ja ootaks.

Selleks on C#-s asünkroonne programmeerimine. Kaks märksõna:

  • async märgib meetodi, mis võib töötada asünkroonselt ehk jääda vahepeal ootele.
  • await ütleb: "oota, kuni see asünkroonne tegevus lõpeb" — aga nii, et arvuti saab vahepeal muud teha.

Põhimõtteliselt mõtle nii: await-ga öeldakse programmile "mine tee päring ära ja tule siis tagasi". Kui vastus saabub, jätkatakse täpselt samast kohast.

Sellepärast kirjutatakse Main meetod asünkroonsena:

using System.Threading.Tasks;

static async Task Main(string[] args)
{
    // siin saame kasutada await-i
}

Task tähistab tegevust, mille tulemust oodatakse. Algajale piisab teadmisest, et async Task Main on mall, mille sees saab await-i kasutada.

Andmete küsimine veebist¶

Lihtsaim viis — GetStringAsync()¶

Kõige lihtsam on küsida kogu vastus ühe sõnena. Meetod GetStringAsync() saadab päringu ja tagastab teenuse vastuse tekstina:

using System.Net.Http;

using HttpClient client = new HttpClient();

string json = await client.GetStringAsync("https://jsonplaceholder.typicode.com/users/1");

Console.WriteLine(json);

Tulemuseks on sama JSON, mille näeksid brauseris. Nüüd saame selle teisendada objektiks täpselt nii, nagu JSON peatükis õppisime.

JSON otse objektiks — GetFromJsonAsync()¶

.NET-is on veelgi mugavam moodus, mis ühendab päringu ja deserialiseerimise ühte meetodisse: GetFromJsonAsync<T>() nimeruumist System.Net.Http.Json. See saadab päringu ja teeb vastusest kohe soovitud tüüpi objekti.

using System.Net.Http;
using System.Net.Http.Json;

// ...

using HttpClient client = new HttpClient();

User user = await client.GetFromJsonAsync<User>(
    "https://jsonplaceholder.typicode.com/users/1");

Console.WriteLine(user.Name);

Selleks on vaja klassi, mille omadused vastavad JSON-i väljadele:

public class User
{
    public int Id { get; set; }
    public string Name { get; set; }
    public string Username { get; set; }
    public string Email { get; set; }
}

Veebi vaikimisi seadistused

GetFromJsonAsync() kasutab n-ö veebi vaikimisi seadeid: see ei arvesta võtmete tõstutundlikkust (Name ja name klapivad) ning oskab arve ka siis lugeda, kui need on JSON-is sõnena. Seetõttu sobib see hästi just API-dest tulnud JSON-iga. Täiendavad JSON-väljad, mida klassis pole, jäetakse lihtsalt vahele.

Vastuse staatuskoodi kontroll¶

Iga HTTP-vastusel on staatuskood, mis ütleb, kuidas päring läks:

Kood Tähendus
200 OK Kõik korras, andmed on olemas
404 Not Found Aadressi või andmeid ei leitud
401 Unauthorized Puudub õigus andmeid küsida
500 Server Error Teenuse poolel tekkis viga

Päringu tulemuse saab kätte GetAsync()-iga, mis tagastab HttpResponseMessage objekti. Seejärel saab staatust kontrollida:

using System.Net;
using System.Net.Http;

using HttpClient client = new HttpClient();

HttpResponseMessage response = await client.GetAsync("https://jsonplaceholder.typicode.com/users/1");

if (response.IsSuccessStatusCode)
{
    string json = await response.Content.ReadAsStringAsync();
    Console.WriteLine(json);
}
else
{
    Console.WriteLine("Päring ebaõnnestus: " + (int)response.StatusCode);
}

IsSuccessStatusCode on true, kui kood on vahemikus 200–299. Nii ei jookse programm kokku, kui teenus vastab veaga.

Näide: kasutajate nimekiri¶

Toome terve kasutajate nimekirja ja trükime iga kasutaja nime ja e-posti.

using System;
using System.Collections.Generic;
using System.Net.Http;
using System.Net.Http.Json;
using System.Threading.Tasks;

using HttpClient client = new HttpClient();

List<User> users = await client.GetFromJsonAsync<List<User>>(
    "https://jsonplaceholder.typicode.com/users");

foreach (User user in users)
{
    Console.WriteLine(user.Name + " — " + user.Email);
}

using System;
using System.Collections.Generic;
using System.Net.Http;
using System.Net.Http.Json;
using System.Threading.Tasks;

namespace InternetApp
{
    public class User
    {
        public int Id { get; set; }
        public string Name { get; set; }
        public string Username { get; set; }
        public string Email { get; set; }
    }

    class Program
    {
        static async Task Main(string[] args)
        {
            using HttpClient client = new HttpClient();

            List<User> users = await client.GetFromJsonAsync<List<User>>(
                "https://jsonplaceholder.typicode.com/users");

            foreach (User user in users)
            {
                Console.WriteLine(user.Name + " — " + user.Email);
            }
        }
    }
}

Kui tahad vastuses vaadata ka muid välju, mida klassis pole (näiteks company või address), võib kasutada ka GetStringAsync()-i ja printida toore JSON-i:

string json = await client.GetStringAsync("https://jsonplaceholder.typicode.com/users/1");
Console.WriteLine(json);

Näide: ilmaandmed¶

Vaata nüüd päris veebiteenust. open-meteo.com pakub tasuta ilmaennustust ilma registreerimiseta. Meid huvitab hetke temperatuur Tallinnas (laiuskraad 59.44, pikkuskraad 24.75).

Aadress koos parameetritega:

https://api.open-meteo.com/v1/forecast?latitude=59.44&longitude=24.75&current=temperature_2m

Vastus näeb välja umbes nii:

{
    "latitude": 59.437,
    "longitude": 24.75,
    "current": {
        "time": "2026-01-15T12:00",
        "temperature_2m": 2.4
    }
}

JSON-is on pesastatud objekt current, mille sees on temperature_2m. Kirjeldame selle klassi kujul:

public class Ilm
{
    public Current Current { get; set; }
}

public class Current
{
    public double Temperature_2m { get; set; }
}

Ja loeme andmed:

using System;
using System.Net.Http;
using System.Net.Http.Json;
using System.Threading.Tasks;

namespace InternetApp
{
    public class Ilm
    {
        public Current Current { get; set; }
    }

    public class Current
    {
        public double Temperature_2m { get; set; }
    }

    class Program
    {
        static async Task Main(string[] args)
        {
            using HttpClient client = new HttpClient();

            string url = "https://api.open-meteo.com/v1/forecast?latitude=59.44&longitude=24.75&current=temperature_2m";

            Ilm ilm = await client.GetFromJsonAsync<Ilm>(url);

            Console.WriteLine("Tallinna temperatuur: " + ilm.Current.Temperature_2m + " °C");
        }
    }
}

Päris andmed, päris tulemus! Samal põhimõttel saab kasutada tuhandeid teisi veebiteenuseid üle maailma.

Päringu parameetrid

Küsimärgiga ? algav osa aadressis on päringuparameetrid. Need on nimi=väärtus paarid, eraldatud ampersandiga &. Näiteks ?latitude=59.44&longitude=24.75&current=temperature_2m ütleb teenusele: "anna laiuskraadil 59.44 ja pikkuskraadil 24.75 hetke temperatuur". Iga teenus dokumenteerib ise, milliseid parameetreid ta ootab.

XML-teenused¶

Osa veebiteenuseid tagastab JSON-i asemel XML-i. Näiteks Eesti ilmateenistus ja paljud vanemad teenused. Nende puhul kasutame sama GetStringAsync()-i, aga vastuse teisendamiseks XmlSerializer-it või XDocument-i, täpselt nagu XML peatükis:

using System.Net.Http;
using System.Xml.Linq;

using HttpClient client = new HttpClient();

string xml = await client.GetStringAsync("https://example.com/andmed.xml");

XDocument doc = XDocument.Parse(xml);
Console.WriteLine(doc.Root.Name);

Skeem on alati sama: päring → vastuse tekst → objektid.

Korduma kippuvad vead¶

System.Net.Http nimeruumi puudumine¶

// VIGA — HttpClient klass puudub
HttpClient client = new HttpClient(); // Viga!

// ÕIGE
using System.Net.Http;
HttpClient client = new HttpClient();

await ilma async meetodita¶

// VIGA — await-i ei saa kasutada tavalises meetodis
static void Main(string[] args)
{
    string json = await client.GetStringAsync(url); // Viga!
}

// ÕIGE — Main peab olema async ja tagastama Task
static async Task Main(string[] args)
{
    string json = await client.GetStringAsync(url);
}

Vigane aadress¶

using System.Net.Http;

// VIGA — aadressil puudub protokoll https://
string url = "jsonplaceholder.typicode.com/users"; // Viga!

// ÕIGE
string url2 = "https://jsonplaceholder.typicode.com/users";

Klassi omadused ei vasta JSON-ile¶

// JSON-is on "name", aga klassis on hoopis Nimi — väli jääb tühjaks
public class User
{
    public string Nimi { get; set; } // jääb null-iks!
}

// ÕIGE — omaduse nimi peab vastama JSON-i väljale (tõstutundlikkus pole oluline)
public class User2
{
    public string Name { get; set; }
}

Kui JSON-i väljanimi ja klassi omadus erinevad täiesti, kasuta JSON peatükist tuntud [JsonPropertyName] atribuuti.

Kokkuvõte¶

Klass / meetod Tähendus
new HttpClient() Loob HTTP-kliendi (implementeerib IDisposable)
client.GetStringAsync(url) Küsib vastuse tekstina
client.GetAsync(url) Küsib vastuse HttpResponseMessage objektina
response.IsSuccessStatusCode Kas päring õnnestus (kood 200–299)
response.StatusCode Vastuse staatuskood
response.Content.ReadAsStringAsync() Vastuse sisu tekstina
response.Content.ReadFromJsonAsync<T>() Vastuse sisu otse objektiks
client.GetFromJsonAsync<T>(url) Päring + JSON-objektiks tegemine ühe meetodiga
static async Task Main Asünkroonne Main, kus saab kasutada await-i
await Ootab asünkroonse tegevuse tulemust

Harjutused¶

  1. Too aadressilt https://jsonplaceholder.typicode.com/users kasutajate nimekiri ja trüki iga kasutaja Id ja Name. Kasuta GetFromJsonAsync<List<User>>().
  2. Too üks postitus aadressilt https://jsonplaceholder.typicode.com/posts/1. Loo klass Post omadustega Id, Title ja Body ning trüki postituse pealkiri ja sisu.
  3. Too aadressilt https://jsonplaceholder.typicode.com/todos ülesannete nimekiri. Loo klass Todo omadustega Id, Title ja Completed. Kasuta LINQ-it, et trükkida ainult lõpetatud ülesanded (Completed == true).
  4. Too open-meteo teenusest hetke temperatuur Tartus (laiuskraad 58.38, pikkuskraad 26.72) ja trüki see koos ühikuga. Vihje: kasuta parameetrit current=temperature_2m.
  5. Kirjuta programm, mis küsib GetAsync()-iga aadressi https://jsonplaceholder.typicode.com/posts/999999 (mida ei ole olemas) ja kontrollib IsSuccessStatusCode abil, kas päring õnnestus. Kui ei õnnestunud, trüki vastuse staatuskood.
  6. Too kasutajate nimekiri ja arvuta LINQ-i abil, mitu kasutajat on kokku ning mitu neist on .biz lõpuga e-posti aadressiga. Trüki tulemus.
