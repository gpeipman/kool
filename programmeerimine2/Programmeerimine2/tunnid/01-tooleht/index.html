Tööleht 1¶

Harjutus 1¶

Harjutuse sisuks on Githubi konto loomine. Ma soovitan konto luua oma isikliku e-posti aadressiga, sest peale kooli lõpetamist on teie kooli e-postid aktiivsed ainult loetud aja. Harjutuse eesmärgiks on tutvuda sisukate Githubi kontode loomisega.

  1. Ava brauser ja liigu Githubi lehele
  2. Kui sul on Githubi konto, siis logi oma kontoga sisse
  3. Kui sul Githubi kontot pole, siis loo omale tasuta konto ja logi sellega sisse
  4. Lisa oma kontole profiili pilt
  5. Lisa oma kontole lühike kirjeldus enda kohta
  6. Lülita sisse kahefaktoriline autentimine (2FA), et Githubi kontole sisse murdmine oluliselt keerukamaks muuta
  7. Vaata oma profiili - sellisena näevad seda ka teised

Harjutus 2¶

Github on lisaks koodihoidlate teenusele ka koht kus ennast tutvustada. Selle jaoks kasutatakse ühte erilist koodihoidlat, mille nimeks on kasutajatunnus. Sinna hoidlasse lisatakse markdown formaadis README.md nimeline fail, kuhu saab enda kohta rohkem kirjutada. Harjutuse eesmärgiks on näidata kuidas enda kohta rohkem infot jagada Githubi keskkonnas.

  1. Loo Githubi uus koodihoidla ja pane sellele nimeks oma Githubi kasutajatunnus
  2. Hoidla loomisel lase Githubil sinna lisada README.md fail
  3. Täida README.md fail (näide allpool) ning salvesta ja lükka hoidlasse
  4. Kui soovid näiteks tehnoloogiate valikut muuta, siis sildid leiad leheküljelt Simple Icons
  5. Vaata oma profiili uuesti

Harjutus 3¶

Harjutuse sisuks on Visual Studio abil lihtsa konsoolirakenduse loomine ja selle lükkamine GitHubi koodihoidlasse.

  1. Ava Visual Studio
  2. Valige "Create a new project"
  3. Valige projekti tüübiks "Console App" (.NET keeltega) või otsige ".NET Console App"
  4. Projekti nimeks pange "TereMaailm"
  5. Jätke kõik muud seaded vaikeväärtusteks ja looge projekt
  6. Visual Studio genereerib teile valmis lihtsa konsoolirakenduse (Hello, World)
  7. Avage GitHub oma brauseris ja looge uus koodihoidla nimega "TereMaailm"
  8. Ärge märkige sisse "Add a README file"
  9. Konto hoidla jäägu avalikuks (public)
  10. Pärast hoidla loomist näete lehekülge kiirjuhistega. Teie jaoks on oluline hoidla URL, mis näeb välja umbes https://github.com/kasutaja/TereMaailm.git
  11. Minge tagasi Visual Studiosse
  12. Avage menüü "View" -> "Git Repository" või klõpsake all paremal nurgas "Add to Source Control"
  13. Looge uus kohalik Git-hoidla: "Create Git Repository" -> "Local only"
  14. Kirjutage sõnum "Esimene commit" ja vajutage "Commit All"
  15. Nüüd minge "Git Repository" aknas ühendatud hoidla vaatesse
  16. Lisage kaugremoot (remote): vajutage "Add Remote", nimeks pange "origin" ja URL-iks oma GitHubi hoidla URL
  17. Lükkage (push) oma kood hoidlasse: "Push" nupp
  18. Minge brauseris oma GitHubi hoidlasse ja kontrollige, et kood on seal

Kui tekib tõrge "remote origin already exists", siis tehke järgmist: - Avage "Git Repository" aken - Paremklõpsake "origin" all ja valige "Remove" - Lisage origin uuesti ja proovige pushida

Harjutus 4¶

Nüüd teeme konsoolirakenduses muudatuse, lükkame selle GitHubi ning vaatame commitite ajalugu.

  1. Visual Studios avage fail Program.cs

  2. Muutke Console.WriteLine("Hello, World!") rea nii, et programm küsib kasutaja nime ja tervitab teda nimepidi:

    Console.Write("Mis su nimi on? ");
string nimi = Console.ReadLine();
Console.WriteLine($"Tere, {nimi}!");

  3. Käivitage rakendus (roheline "Run" nupp või klahv F5) ja veenduge, et see töötab

  4. Avage "Git Repository" aken (vaade "View" -> "Git Repository")
  5. Näete seal muudetud faili Program.cs. Kirjutage commit-sõnumiks "Lisatud nime küsimine" ja vajutage "Commit All"
  6. Vajutage "Push" nuppu, et muudatus GitHubi lükata
  7. Minge brauseris oma GitHubi hoidlasse ja kontrollige, et muudatus on seal näha
  8. Minge tagasi Visual Studiosse, "Git Repository" aknas vajutage "View History" või klõpsake üleval commiti ajaloo ikooni
  9. Vaadake commitite ajalugu – näete kahte committi: "Esimene commit" ja "Lisatud nime küsimine"
  10. Klõpsake ühel commitil – näete täpselt, millised failid muutusid ja mis ridu lisati/eemaldati
