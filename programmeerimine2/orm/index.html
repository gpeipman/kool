Object-Relational Mapper (ORM)¶

ORM on tehnoloogia, mis ühendab kaks erinevat maailma: objektid (C# kood) ja relatsioonilised andmebaasid (tabelid SQL andmebaasis). Klassikaline SQL andmebaas ei oska ise objektidega midagi teha. Kui soovime andmebaasiga suhelda, siis peame selleks kasutama SQL-keelseid käske, millest andmebaas aru saab. ORM võimaldab meil töötada objektidega, mille andmed on andmebaasis. SQL-keelsed käsud objektide küsimiseks, salvestamiseks ja eemaldamiseks koostab ORM automaatselt.

Märkus

Selles aines puutume andmebaasidega kokku pealiskaudselt. Põhjalikumad arusaamad andmebaasidest ja oskused nendega töötamiseks omate andmebaaside aines.

Probleem¶

Kui kirjutad tavalist C# rakendust, töötad klasside ja objektidega:

public class Book
{
    public int Id { get; set; }
    public string Title { get; set; }
    public string Author { get; set; }
}

Ilma ORM-ita pead ise kirjutama SQL päringuid ja teisendama need käsitsi objektideks:

// Ilma ORM-ita – pead ise kõik teisendama
var sql = "SELECT Id, Title, Author FROM Books";
var command = new SqlCommand(sql, connection);
var reader = command.ExecuteReader();

var books = new List<Book>();
while (reader.Read())
{
    books.Add(new Book
    {
        Id = (int)reader["Id"],
        Pealkiri = reader["Pealkiri"].ToString(),
        Autor = reader["Autor"].ToString()
    });
}

See on tüütu, veaohtlik ja igav. Antud näide ei too välja koodi, mida peame kirjutama juhtudeks kui mõnel omadusel puudub andmebaasis väärtus. Lisaks ärme unusta, et ilma ORM-ita peame koostama SQL-käsud ka objektide salvestamiseks ja kustutamiseks.

Lahendus: ORM¶

ORM teisendab automaatselt:

C# objekt ←→ Andmebaasi tabel
C# SQL
Klass Tabel
Objekt Rida
Omadus Veerg
book.Title = "..." Title = '...'
db.Books.Add(book) INSERT INTO Books ...
db.SaveChanges() COMMIT

Andmebaasiga suhtleva andmekihi loomine on lihtne ainult alguses kui tabeleid ja päringuid on vähe. Süsteemi kasvades hakkavad kasvama ka keerukused andmekihis ja siis tuleb ebameeldiva üllatusena välja, et hea andmekihi kirjutamine on siiski väga keerukas töö. Head ORM-id peidavad meie eest mitmed keerukused, millega peaksime vastasel korral tegelema ise.
