Harjutus: Entity Framework Core rakendus¶

Entity Framework Core (EF Core) on .NET raamistiku poolt pakutav object-relational mapper (ORM). ORM on komponent, mis automatiseerib andmebaasiga suhtlemist. Oma rakenduse koodis kasutame me klasse, mille andmeid soovime hoida andmebaasis. Me võiksime kirjutada ka käsitsi sellist koodi, mis saadab päringuid andmebaasi ja loob saadud tulemustest objekte, kuid see pealtnäha lihtne ülesanne kasvab päris kähku küllaltki keerukaks.

Meile tuleb appi EF Core, mille abil saame me kirjutada oma klassidel baseeruvaid LINQ-päringuid. EF Core teisendab need ise andmebaasi päringuteks ning loob meile päringute põhjal objektid.

Harjutuse eesmärgiks on ASP.NET Core veebirakenduse näitel tutvuda EF Corega ja LINQ-päringutega. Selle harjutuse tulemusena saame esimesed kogemused andmebaaside kasutamisega .NET Core raamistikus ning näeme kuidas käib veebirakenduse kaudu andmete haldamine.

Ülesanne: Loo klassid ja seo need Entity Frameworki DbContextiga¶

  • Ava Githubist oma klassiskeem
  • Loo need klassid KooliProjekt.Application projektis Data kausta
  • Lisa need klassid ka samas kaustas olevasse DbContexti (klass nimega ApplicationDbContext)
  • Kompileeri ja veendu, et ei oleks vigu
  • Kui muutsid klasside ülesehitust, siis uuende ka klassiskeemi ja dokumentatsiooni

Ülesanne: Lisa uus migratsioon¶

  • Loo uus migratsioon
    • Vali Tools menüüst Package Manager
    • Sisesta järgnev käsk: Add-Migration InitialCreate
    • Sisesta järgnev käsk: Update-Database
  • Veendu, et vigu ei tekkinud ja arvutisse tekkis andmebaas koos tabelitega

Ülesanne: Lisa algandmete tugi¶

  • Lisa oma projekti Data kausta klass nimega SeedData
  • SeedData klassis kontrolli kas tabelites on andmeid või ei (võta mõni keskne tabel selleks)
  • Kui tabelis andmeid pole, siis lisa testandmed kõikidesse tabelitesse
  • Vaata õpetaja näitest SeedData klassi ja tee selle järgi
  • Lase programm käima ja veendu, et tabelitesse tekkisid andmed
